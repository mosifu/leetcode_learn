# LeetCode 167：两数之和 II —— 双指针解法总结

## 一、解题思路

题目给定一个**非递减排序数组** `numbers` 和目标值 `target`，要求返回两个元素的下标，且下标从 `1` 开始，并且只能使用常数级额外空间。

使用**双指针**，分别定义左指针 `left = 0` 和右指针 `right = numbers.length - 1`，从数组两端向中间移动。

1. 计算 `sum = numbers[left] + numbers[right]`。
2. 如果 `sum == target`，返回 `{left + 1, right + 1}`。
3. 如果 `sum > target`，说明和太大，由于数组有序，右指针左移。
4. 如果 `sum < target`，说明和太小，左指针右移。
5. 当找到答案时返回结果。

## 二、为什么双指针有效？

数组已经升序排列：

- 右端元素最大，若当前和过大，移动 `right` 可以减小总和。
- 左端元素较小，若当前和过小，移动 `left` 可以增大总和。

每次移动都能排除一部分不可能的组合，避免暴力解法枚举所有元素对。

## 三、Java 知识点

- `int left = 0`：初始化左指针。
- `int right = numbers.length - 1`：初始化右指针。
- `while (left < right)`：确保两个指针不重合，避免重复使用同一元素。
- `left++`、`right--`：分别向右、向左移动指针。
- `new int[]{left + 1, right + 1}`：题目要求下标从 `1` 开始，因此需要将 Java 的零基下标加 `1`。

## 四、复杂度分析

- **时间复杂度：** \(O(n)\)，每轮至少移动一个指针，最多遍历数组一次。
- **空间复杂度：** \(O(1)\)，只使用固定数量的变量，满足题目要求。

相比之下，哈希表解法平均时间复杂度为 \(O(n)\)，但额外空间复杂度为 \(O(n)\)，不符合本题的空间要求。

## 五、核心总结

双指针适用于有序数组中寻找满足特定条件的元素组合。关键是利用排序性质，根据当前结果决定移动哪个指针，而不是盲目遍历。注意区分 Java 的零基下标与题目要求的一基下标。
