# LeetCode 704：二分查找

## 一、解题思路

本题要求在升序数组中查找目标值，并且时间复杂度必须为 \(O(\log n)\)，因此使用**二分查找**。核心思想是每次比较中间元素与目标值，排除一半不可能包含目标值的区间，从而缩小搜索范围。

本题采用**左闭右开区间**，即 `[left, right)`。初始化 `left = 0`，`right = nums.length`，表示搜索范围包含左边界，但不包含右边界。

1. 计算中间下标：`mid = (left + right) / 2`。
2. 如果 `nums[mid] == target`，说明找到目标值，返回 `mid`。
3. 如果 `nums[mid] < target`，目标值可能在右侧，将左边界更新为 `mid + 1`。
4. 如果 `nums[mid] > target`，目标值可能在左侧，将右边界更新为 `mid`。
5. 当 `left == right` 时，搜索区间为空，说明没有找到目标值，返回 `-1`。

每次循环都会缩小搜索范围，最终找到目标值或确定其不存在。

## 二、Java知识总结

- **数组长度**：使用 `nums.length` 获取数组元素个数，不需要加括号。
- **循环判断**：`while (left < right)` 保证区间非空时继续查找。
- **整数除法**：Java中两个整数相除会舍弃小数部分，因此 `(left + right) / 2` 可以得到整数下标。
- **边界更新**：左闭右开区间中，右边界不包含在搜索范围内，因此右移搜索边界时使用 `right = mid`；排除中间元素后，左边界使用 `left = mid + 1`。
- **复杂度分析**：时间复杂度为 \(O(\log n)\)，额外空间复杂度为 \(O(1)\)。

注意：`mid` 必须在每轮边界更新后重新计算，否则可能重复检查同一个位置，导致循环无法结束。实际编写时，也可以使用 `left + (right - left) / 2` 计算中间下标，避免 `left + right` 在极大数组下发生整数溢出。
