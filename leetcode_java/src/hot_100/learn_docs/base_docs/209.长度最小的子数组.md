# LeetCode 209：长度最小的子数组

## 一、解题思路

本题使用**滑动窗口（快慢指针）**。定义 `fast` 为窗口右边界，`slow` 为左边界，`sum` 记录窗口内元素之和，`min_len` 记录满足条件的最小长度。

1. 初始化 `fast = 0`、`slow = 0`、`sum = 0`，并将 `min_len` 设置为 `Integer.MAX_VALUE`。
2. 移动 `fast`，将当前元素加入 `sum`，扩大窗口。
3. 当 `sum >= target` 时，说明当前窗口满足条件，更新最小长度 `fast - slow + 1`。
4. 将 `nums[slow]` 从 `sum` 中减去，并移动 `slow`，尝试缩小窗口。只要窗口仍满足条件，就持续缩小。
5. 遍历结束后，如果 `min_len` 仍是初始值，说明不存在符合条件的子数组，返回 `0`；否则返回 `min_len`。

## 二、核心知识点

- **滑动窗口**：通过移动左右边界，动态维护连续子数组，避免重复计算区间总和。
- **双指针**：`fast` 扩大窗口，`slow` 缩小窗口。
- **嵌套 `while` 循环**：外层负责扩张，内层负责满足条件后尽可能收缩。
- **`Integer.MAX_VALUE`**：用作最小长度的初始哨兵值，最后判断是否找到有效解。
- **`Math.min(a, b)`**：比较两个值并返回较小值，用于更新最小长度。

## 三、复杂度分析

- 时间复杂度：`O(n)`。两个指针都只向右移动，每个元素最多被加入和移出窗口一次。
- 空间复杂度：`O(1)`。只使用固定数量的变量。

**注意：** 本方法依赖数组元素均为正整数。正因为元素为正，缩小窗口才会使 `sum` 减小；如果数组包含负数，这种滑动窗口策略就不一定适用。
