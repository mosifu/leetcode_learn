# LeetCode 3：无重复字符的最长子串

## 一、解题思路

本题使用**滑动窗口 + HashSet + 双指针**。`left` 和 `right` 分别表示窗口左右边界，`strSet` 用于存储当前窗口中的字符，`max_len` 记录最长无重复子串的长度。

1. 初始化左右指针为 `0`，最大长度为 `0`。
2. 当 `right` 未超出数组边界时，判断当前字符是否存在于 `strSet` 中。
3. 如果存在重复字符，移除 `strToList[left]`，并将 `left` 右移一位。此时不移动 `right`，继续检查当前字符。
4. 如果不存在重复字符，将当前字符加入集合，更新 `max_len`，再将 `right` 右移。
5. 遍历结束后，返回 `max_len`。

## 二、上次错误代码的原因分析

上次使用 `Set<String>` 时，存在一个重要的**类型匹配问题**：`strToList[right]` 的类型是 `char`，而集合要求的元素类型是 `String`。因此，`contains(strToList[right])` 和 `remove(strToList[left])` 都没有正确匹配集合元素类型。应统一使用 `String.valueOf()` 转换后再操作。

修改为 `Set<Character>` 后，字符可以直接存入、查询和删除，避免了类型不匹配问题。注意：之前代码中 `add(String.valueOf(...))` 本身没有问题，真正需要修改的是所有集合操作的类型保持一致。

## 三、核心知识点

- `toCharArray()`：将字符串转换为字符数组，方便按索引访问。
- `HashSet`：利用 `contains()` 判断字符是否重复，平均时间复杂度为 \(O(1)\)。
- **滑动窗口**：遇到重复字符时，持续缩小左边界，直到可以重新加入当前字符。
- `Math.max(a, b)`：更新最长窗口长度。
- 时间复杂度：\(O(n)\)；空间复杂度：\(O(\min(n, 字符集大小))\)。

**注意：** 当前代码中 `Set<Character>` 与 `char` 类型匹配正确；遇到重复字符时只移动左指针、不移动右指针，是为了确保当前字符最终能够加入窗口。
