# LeetCode 141：环形链表

## 一、解题思路：快慢指针

使用快慢指针判断链表是否存在环。初始化 `slow` 和 `fast` 都指向头节点。每轮循环中，`slow` 移动一步，`fast` 移动两步。如果链表无环，`fast` 最终会到达 `null`，循环结束并返回 `false`；如果链表有环，快指针会在环内追上慢指针，此时 `slow == fast`，返回 `true`。

循环条件 `Objects.nonNull(fast) && Objects.nonNull(fast.next)` 保证快指针及其后继节点都不为空，避免访问空引用的 `next` 属性。

时间复杂度为 \(O(n)\)，额外空间复杂度为 \(O(1)\)。

## 二、Java 中 `==` 比较什么？

### 1. 基本数据类型

对于 `int`、`double`、`char`、`boolean` 等基本类型，`==` 比较的是**值是否相等**。

```java
int a = 10;
int b = 10;
System.out.println(a == b); // true
```

### 2. 引用数据类型

对于对象、数组等引用类型，`==` 比较的是**两个引用是否指向同一个对象**，而不是对象内容是否相同。

```java
ListNode a = new ListNode(1);
ListNode b = new ListNode(1);
System.out.println(a == b); // false
```

虽然两个节点的 `val` 都是 `1`，但它们是分别创建的两个对象。

```java
ListNode c = a;
System.out.println(a == c); // true
```

`c = a` 复制的是引用，因此二者指向同一个节点。

### 3. 为什么本题使用 `slow == fast`？

本题判断的是快慢指针是否到达**同一个节点对象**，而不是节点值是否相同。即使两个节点的 `val` 都是 `3`，只要它们不是同一个节点，`slow == fast` 就是 `false`。因此不能写成 `slow.val == fast.val`，否则可能误判。

补充：`Objects.nonNull(fast)` 等价于 `fast != null`，用于判断引用是否非空；`Objects` 是 `java.util` 中的工具类。
