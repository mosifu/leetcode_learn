# LeetCode 21：合并两个有序链表

## 一、解题思路

采用**双指针 + 虚拟头节点**。创建 `dummy` 作为虚拟头节点，`current` 指向当前合并链表的尾部。每次比较 `list1.val` 和 `list2.val`，将较小节点连接到 `current.next`，再移动对应链表的指针。每轮比较后，`current` 向后移动。当其中一个链表遍历结束，将另一个链表剩余部分直接接到 `current.next`，最后返回 `dummy.next`。

## 二、Java 知识点

1. **静态内部类与构造方法**：`public static class ListNode` 定义链表节点，包含 `int val` 和 `ListNode next`。`new ListNode(n)` 创建节点，`this.val = val` 中的 `this` 表示当前对象。

2. **引用变量与节点连接**：`ListNode current = dummy` 是引用赋值，不会复制节点。`current.next = list1` 修改节点的连接关系；`current = current.next` 则改变变量 `current` 的指向。两者含义不同。

3. **虚拟头节点**：`dummy` 是辅助节点，简化首个真实节点的连接逻辑。最终返回 `dummy.next`，而不是 `dummy`。

4. **`while` 与逻辑运算符**：`while (list1 != null && list2 != null)` 表示两个链表都还有节点时才比较。`&&` 需要两侧条件均为真；当任一指针为 `null`，循环结束。

5. **增强 `for` 循环**：`for (int n : list)` 依次读取数组元素，用于构建链表。每次通过 `new ListNode(n)` 创建节点，再连接到尾部。

6. **静态方法与实例方法**：`buildListNodeList()`、`printListNode()` 声明为 `static`，可以直接通过类调用；`mergeTwoLists()` 是实例方法，因此在 `main` 中先创建 `obj`，再调用 `obj.mergeTwoLists()`。

## 三、复杂度与注意事项

设两个链表长度分别为 \(m\)、\(n\)，时间复杂度为 \(O(m+n)\)，辅助空间复杂度为 \(O(1)\)，因为合并时复用原节点。注意：你的代码中 `current = current.next` 放在 `if-else` 外部是正确的，能保证每轮连接后都移动尾指针。
