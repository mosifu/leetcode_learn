# LeetCode 206：反转链表

## 一、解题思路（约 30%）

采用**迭代 + 三指针**的方式反转单链表。`pre` 指向已经反转部分的头节点，`head` 指向当前处理的节点，`next` 暂存当前节点的后继节点。

每轮循环依次执行：
1. 保存 `head.next` 到 `next`，避免后续修改指针后丢失剩余链表。
2. 将 `head.next` 指向 `pre`，反转当前节点的指向。
3. `pre = head`，让已反转部分向前扩展。
4. `head = next`，继续处理下一个节点。

循环结束时，`head == null`，说明原链表已经遍历完毕，`pre` 就是反转后的头节点，因此返回 `pre`。时间复杂度为 \(O(n)\)，额外空间复杂度为 \(O(1)\)。

## 二、Java 语法知识（约 70%）

### 1. 定义静态内部类 `ListNode`

`public static class ListNode` 是定义在 `ReverseLinkedList_206` 内部的类，用来表示链表节点。`static` 表示创建节点时不需要先创建外部类对象。

```java
int val;       // 存储节点值
ListNode next; // 存储下一个节点的引用
```

`ListNode next` 并不是把整个节点复制进去，而是保存指向另一个节点的引用。`next == null` 表示没有后继节点。

### 2. 构造方法与 `this`

```java
ListNode() {}
ListNode(int val) { this.val = val; }
ListNode(int val, ListNode next) {
    this.val = val;
    this.next = next;
}
```

构造方法名称必须与类名相同，且没有返回类型。创建节点时，`new ListNode(1)` 会调用第二个构造方法。

`this.val` 表示当前对象的成员变量，`val` 表示传入的参数。当两者同名时，使用 `this` 区分。`this.next = next` 同理。

### 3. 引用变量与 `null`

```java
ListNode pre = null;
```

`pre` 是引用变量，保存节点的引用；`null` 表示当前没有指向任何对象。最初没有已反转的节点，因此 `pre` 为 `null`。

### 4. `while` 与条件判断

```java
while (head != null) {
    // ...
}
```

只要 `head` 不为 `null`，就继续处理当前节点。空链表的 `head` 一开始就是 `null`，循环不会执行，最终返回 `null`，自然支持空链表。

### 5. 引用赋值与指针修改

```java
ListNode next = head.next;
head.next = pre;
pre = head;
head = next;
```

这里的赋值分为两种理解：

- `next = head.next`：复制的是**引用**，不是复制节点对象。之后即使修改 `head.next`，`next` 仍保存原来后继节点的引用。
- `head.next = pre`：修改当前节点对象的 `next` 成员，让它指向前一个节点。
- `pre = head`、`head = next`：改变引用变量指向的对象，不会复制或移动节点本身。

因此，四行代码的顺序非常重要：**先保存后继节点，再反转连接，最后移动两个引用变量。**
