# LeetCode 303：区域和检索 - 数组不可变

## 一、解题思路：前缀和

本题需要多次查询数组中闭区间 `[left, right]` 的元素之和。如果每次查询都遍历区间，时间复杂度为 \(O(n)\)。因此使用**前缀和**，提前计算从数组开头到各位置的累计和，将查询时间优化到 \(O(1)\)。

定义 `sums[i]` 表示 `nums` 前 `i` 个元素之和，即 `nums[0]` 到 `nums[i-1]` 的总和。创建长度为 `nums.length + 1` 的数组，让 `sums[0] = 0` 作为初始边界。遍历原数组，通过 `sums[i+1] = sums[i] + nums[i]` 计算累计和。

查询时，利用 `sums[right+1] - sums[left]` 消除区间左侧的累计部分，得到 `[left, right]` 的元素之和。初始化时间复杂度为 \(O(n)\)，每次查询为 \(O(1)\)，额外空间复杂度为 \(O(n)\)。

## 二、重点 Java 知识

1. **静态嵌套类**：`static class NumArray` 不依赖外部类对象，可以直接在外部类的 `main` 方法中创建。
2. **成员变量**：`private final int[] sums` 定义对象的成员变量，供构造方法和 `sumRange()` 共同使用；`private` 限制外部直接访问。
3. **构造方法**：`public NumArray(int[] nums)` 与类名相同且没有返回类型，在 `new NumArray(nums)` 时自动执行，负责初始化前缀和。
4. **final 关键字**：要求 `sums` 引用只能赋值一次，但不禁止修改数组元素。
5. **数组与循环**：`nums.length` 获取数组长度；`for` 循环逐个计算累计和；`sums[i+1]` 利用下标偏移避免区间计算时处理左边界的特殊情况。

**核心记忆：** 前缀和适合数组内容不变、但需要多次查询区间和的场景。若数组元素需要频繁更新，则应考虑其他数据结构，例如树状数组或线段树。
