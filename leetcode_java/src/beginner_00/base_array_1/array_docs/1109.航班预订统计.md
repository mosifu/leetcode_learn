# LeetCode 1109：航班预订统计

## 一、解题思路：差分数组 + 前缀和

本题要求统计每个航班的预订座位总数。若直接遍历每条预订记录，并给起始航班到结束航班的每个位置加上座位数，最坏时间复杂度为 \(O(mn)\)，其中 \(m\) 是预订记录数，\(n\) 是航班数。使用差分数组可以将每条记录的处理优化为 \(O(1)\)。

**1. 构建差分数组**

创建 `int[] diff = new int[n + 1]`。差分数组记录座位数在各位置的变化，而不是每个航班的实际座位总数。对于预订记录 `[first, last, seats]`，航班编号从 1 开始，而 Java 数组索引从 0 开始，因此起点索引为 `first - 1`，终点之后的索引为 `last`。

执行 `diff[first - 1] += seats`，表示从起始航班开始增加这些座位；执行 `diff[last] -= seats`，表示从结束航班的下一个航班开始撤销这次增加的座位。这样就只需修改两个位置，表示整个区间的影响。数组长度设为 `n + 1`，可容纳索引 `n`，处理结束航班为 `n` 的记录时不会越界。

**2. 还原每个航班的座位数**

遍历 `diff` 的前 `n` 个元素，累加变化量：`answer[i] = current_seats + diff[i]`，再令 `current_seats = answer[i]`。这相当于对差分数组求前缀和，逐个还原每个航班的实际预订总数。

## 二、Java 知识点与复杂度

`for (int[] booking : bookings)` 是增强 for 循环，每次取出一条预订记录；`booking[0]`、`booking[1]`、`booking[2]` 分别表示起始航班、结束航班和座位数。

设预订记录数为 \(m\)，构建差分数组需要 \(O(m)\)，还原答案需要 \(O(n)\)，总时间复杂度为 \(O(m+n)\)。差分数组和答案数组均占用 \(O(n)\) 空间，因此空间复杂度为 \(O(n)\)。
