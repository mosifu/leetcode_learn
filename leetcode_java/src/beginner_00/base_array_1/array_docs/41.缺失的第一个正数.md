# 41. 缺失的第一个正数

## 一、解题思路：原地哈希 + 交换

题目要求时间复杂度为 \(O(n)\)，额外空间复杂度为 \(O(1)\)。使用额外哈希表会占用线性空间，因此可以直接利用原数组，将数字放到与其对应的位置上。

对于长度为 `n` 的数组，最小缺失正数一定在 `1` 到 `n+1` 之间。若数字 `x` 满足 `1 <= x <= n`，就应该将它放到索引 `x-1` 的位置，即让 `nums[x-1] = x`。

使用 `while` 遍历数组：若当前数字在有效范围内，且它尚未位于正确位置，就交换它与目标位置上的数字；否则，当前元素无法继续调整，索引 `i` 才向后移动。重复交换，直到当前位置的数字归位，或不满足交换条件。

数组调整完成后，再从头遍历。如果发现 `nums[j] != j+1`，说明正整数 `j+1` 缺失，直接返回；若所有位置都正确，则返回 `n+1`。

## 二、Java 知识点

- **`while` 循环**：适合一个位置可能需要多次交换的场景。只有当前元素处理完毕后，才递增索引。
- **数组索引**：数组索引从 `0` 开始，因此数字 `x` 对应索引 `x-1`。
- **逻辑运算符 `&&`**：多个条件必须同时成立才执行交换。Java 会短路求值，先判断 `1 <= curr_num && curr_num <= nums.length`，再访问 `nums[curr_num-1]`，避免索引越界。
- **原地修改数组**：直接交换数组元素，不创建额外数组或哈希表，因此辅助空间为 \(O(1)\)。
- **`return`**：找到第一个不符合位置规律的元素后立即结束方法；若遍历结束仍未发现缺失值，则返回 `nums.length+1`。

## 三、复杂度分析

时间复杂度为 \(O(n)\)：虽然存在嵌套在 `while` 中的交换操作，但每次有效交换都会将一个数字放到正确位置，整体交换次数为线性级别。最后的检查再遍历一次数组，仍为 \(O(n)\)。

额外空间复杂度为 \(O(1)\)：只使用固定数量的变量，直接修改原数组。

**注意：**该方法会改变传入的 `nums` 数组。
