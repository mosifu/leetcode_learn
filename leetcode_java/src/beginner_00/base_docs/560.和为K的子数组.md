# LeetCode 560：和为 K 的子数组

## 一、解题思路：前缀和 + 哈希表

本题要求统计数组中和为 `k` 的连续非空子数组个数。定义 `pre_sums[i]` 为 `nums` 前 `i` 个元素的和，则区间 `[left, right]` 的和为 `pre_sums[right+1] - pre_sums[left]`。因此，只需查找是否存在前缀和等于 `i_sum - k`。

代码先构建前缀和数组，再使用 `HashMap<Integer, Integer>` 记录每种前缀和出现的次数。遍历时，先计算 `other = i_sum - k`，若哈希表存在该键，就将其出现次数累加到 `count`；然后更新当前前缀和的出现次数。**必须先查询、再更新**，避免把当前前缀和当成之前出现的前缀和。前缀和数组的首元素为 `0`，可正确统计从下标 `0` 开始的子数组。

## 二、Java 相关知识点

1. **数组与前缀和**：`new int[nums.length + 1]` 创建前缀和数组，元素默认初始化为 `0`；通过 `pre_sums[i + 1] = pre_sums[i] + nums[i]` 逐步计算。
2. **增强 for 循环**：`for (int i_sum : pre_sums)` 会依次取出数组中的每个元素赋给 `i_sum`，不需要手动维护下标，适合只关心元素值的遍历。它等价于依次访问 `pre_sums[0]` 到 `pre_sums[pre_sums.length - 1]`，但不能直接通过 `i_sum` 修改数组对应元素。
3. **泛型与包装类**：`Map<Integer, Integer>` 表示键和值都是 `Integer` 的映射。Java 泛型不能使用基本类型 `int`，所以需要包装类 `Integer`。
4. **哈希表操作**：`containsKey()` 判断键是否存在，`get()` 获取对应次数，`put()` 插入或更新键值对。
5. **三元运算符**：`condition ? a : b` 根据条件选择结果。代码用它实现已有次数加一，否则初始化为 `1`。
6. **复杂度**：设数组长度为 `n`，时间复杂度为 `O(n)`，空间复杂度为 `O(n)`。

**注意**：数组可能包含负数，窗口和不一定单调变化，因此普通滑动窗口不适用于所有情况；前缀和加哈希表可以处理正数、零和负数。
