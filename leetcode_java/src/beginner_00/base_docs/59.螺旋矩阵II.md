# LeetCode 59：螺旋矩阵 II

## 一、解题思路

本题要求将 `1` 到 `n²` 按顺时针方向填入 `n × n` 矩阵。采用**模拟法 + 分层遍历**，按照上、右、下、左四个方向依次填充，每完成一圈后向内收缩边界。

1. **初始化**：创建 `int[][] matrix = new int[n][n]`，使用 `index` 表示当前圈数，`count` 表示待填入的数字，从 `1` 开始。
2. **上边**：固定行 `index`，列从左向右遍历。
3. **右边**：固定列 `n-1-index`，行从上向下遍历。
4. **下边**：固定行 `n-1-index`，列从右向左遍历。
5. **左边**：固定列 `index`，行从下向上遍历。
6. **收缩边界**：每完成一圈，`index++`，继续填充内层矩阵。最后若 `n` 为奇数，中心位置尚未填充，将 `count` 赋给 `matrix[n/2][n/2]`。

## 二、Java知识总结

- **二维数组**：`new int[n][n]` 创建正方形矩阵，使用 `matrix[i][j]` 访问元素。
- **嵌套循环**：通过 `for` 控制行列下标，递增表示正向遍历，递减表示反向遍历。
- **取余判断奇偶**：`n % 2 == 1` 表示正整数 `n` 为奇数。
- **整数除法**：`n / 2` 会舍弃小数部分，可用于定位中心下标。
- **循环边界**：`j < n-1-index` 等写法避免重复填写四个角，防止同一元素被多次覆盖。

## 三、复杂度分析

每个矩阵元素只需填充一次，时间复杂度为 \(O(n^2)\)；返回的矩阵占用 \(O(n^2)\) 空间，若不计输出矩阵，额外空间复杂度为 \(O(1)\)。

注意：当前代码的 `while (count < n*n)` 可能提前退出，导致最后一圈未填满。例如 `n=3` 时，`count` 填到 `8` 后循环就会结束，中心补 `9` 虽然正确，但 `n=4` 时会遗漏元素。更稳妥的方式是以 `index < n / 2` 控制外圈，并在奇数情况下单独填写中心。

# 补充：边界收缩法

## 一、解题思路

使用 `top`、`bottom`、`left`、`right` 四个变量控制矩阵边界，按顺时针方向依次填充：上边从左向右、右边从上向下、下边从右向左、左边从下向上。每完成一个方向，就收缩对应边界，直到填满 `1` 到 `n²`。

## 二、每轮边界变化示例

以 `n = 3` 为例，初始边界为 `top=0, bottom=2, left=0, right=2`。

| 阶段 | 填充方向 | 填入数字 | 边界变化 |
|---|---|---|---|
| 第一轮 | 上边 | 1、2、3 | `top: 0→1` |
| 第一轮 | 右边 | 4、5 | `right: 2→1` |
| 第一轮 | 下边 | 6、7 | `bottom: 2→1` |
| 第一轮 | 左边 | 8 | `left: 0→1` |
| 第二轮 | 中心 | 9 | 填充结束 |

最终矩阵：

```text
1 2 3
8 9 4
7 6 5
```

边界每收缩一次，就排除已经填充的行或列，剩余区域逐渐缩小。

## 三、Java知识与适用场景

`int[][] matrix = new int[n][n]` 创建二维数组；`for` 循环控制遍历方向，`++`、`--` 更新边界。该方法适用于螺旋矩阵、矩阵逐层遍历等问题。

时间复杂度为 **O(n²)**，额外空间复杂度为 **O(1)**（不计结果矩阵）。

**注意：** 原代码在最后一圈边界重合时可能重复填充或越界。每次遍历前应检查 `top <= bottom`、`left <= right`，并在每个方向填充后判断是否已经完成，确保正确处理 `n=1` 及奇数、偶数矩阵。
