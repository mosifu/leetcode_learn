# LeetCode 26：删除有序数组中的重复项

## 一、解题思路

本题使用**快慢双指针**，在不创建新数组的情况下原地去重。由于数组是非严格递增排列，相同元素必然相邻，因此只需比较当前读指针与写指针对应的元素。

1. 初始化 `read = 0`、`write = 0`，分别表示读指针和写指针。
2. 当 `read < nums.length` 时，遍历数组。
3. 如果 `nums[read] == nums[write]`，说明当前元素与已保留的最后一个唯一元素相同，只移动 `read`。
4. 如果两者不同，说明发现了新的唯一元素，先移动 `write`，再将 `nums[read]` 写入 `nums[write]`。
5. 遍历结束后，返回 `write + 1`，即唯一元素的数量。

## 二、核心 Java 知识点

- **双指针**：`read` 负责遍历原数组，`write` 负责记录唯一元素的存放位置。
- **原地修改**：直接覆盖 `nums` 中的元素，不需要额外数组。
- **数组索引**：数组从下标 `0` 开始，因此最后一个唯一元素的下标加 `1` 才是元素数量。
- **`while` 循环**：通过 `read < nums.length` 防止访问越界。
- **相对顺序**：由于数组有序，新元素按遍历顺序写入，不会改变唯一元素的排列顺序。

## 三、复杂度分析

- 时间复杂度：`O(n)`，读指针最多遍历数组一次。
- 空间复杂度：`O(1)`，只使用两个指针，不额外创建数组。

## 四、注意事项

当前代码默认数组非空。如果 `nums.length == 0`，循环不会执行，但最终返回 `write + 1` 会得到 `1`，这是错误的。建议在方法开头添加 `if (nums.length == 0) return 0;`，以正确处理空数组。
