# LeetCode 56：合并区间

## 一、解题思路：排序 + 贪心

本题要求合并所有重叠区间。核心思路是先按区间起点升序排序，再依次遍历，利用 `current_interval` 保存当前正在合并的区间，利用 `res` 保存已经确定不再变化的合并结果。

**1. 排序：** 使用 `Arrays.sort(intervals, Comparator.comparingInt(a -> a[0]))`，按照每个区间的起点升序排列。排序后，后续区间的起点不会小于前面区间的起点，因此只需比较当前合并区间的终点与下一个区间的起点。

**2. 判断重叠并合并：** 若 `current_interval[1] >= interval[0]`，说明两个区间重叠或端点相接，将当前终点更新为 `Math.max(current_interval[1], interval[1])`，确保覆盖两个区间。若当前终点小于下一区间的起点，说明两者不重叠，将当前区间加入 `res`，再令 `current_interval = interval`，开始处理新区间。

**3. 收尾并返回：** 循环结束后，最后一个 `current_interval` 尚未加入结果，因此需要执行 `res.add(current_interval)`。最后通过 `res.toArray(new int[0][])` 将集合转换为题目要求的 `int[][]`。

时间复杂度为 \(O(n\log n)\)，主要来自排序；遍历为 \(O(n)\)。结果集合额外占用 \(O(n)\) 空间。

## 二、Java 相关知识

- **`Arrays` 工具类：** 提供 `sort()` 等静态方法；这里直接对原数组排序。
- **`Comparator` 接口：** `comparingInt(a -> a[0])` 创建按区间起点比较的规则，`a` 是一个 `int[]`。
- **增强 for 循环：** `for (int[] interval : intervals)` 依次取得每个区间，不必手动使用下标。
- **`Math.max()`：** 返回两个整数中的较大值，用于更新合并区间的终点。
- **`List<int[]>`：** 集合的每个元素都是一个一维整数数组，适合动态存放合并结果。
- **`toArray(new int[0][])`：** 将 `List<int[]>` 转换为 `int[][]`。也可以使用 Java 11 及以上的 `res.toArray(int[][]::new)`。

**注意：** 你的代码默认 `intervals` 非空；若题目允许空数组，需要提前判断，否则访问 `intervals[0]` 会抛出异常。
