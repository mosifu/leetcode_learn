# LeetCode 232：用栈实现队列

## 一、解题思路

使用两个栈模拟队列的先进先出（FIFO）特性：

- `inStack`：入栈，负责接收新元素。
- `outStack`：出栈，负责弹出队头元素。

`push(x)`：将元素压入 `inStack`。

`pop()` 和 `peek()`：如果 `outStack` 为空，则将 `inStack` 的所有元素依次弹出并压入 `outStack`，实现顺序反转；然后分别使用 `pop()` 删除队头或 `peek()` 查看队头。

`empty()`：两个栈都为空时，队列才为空。

每个元素最多转移一次，因此 `push`、`pop`、`peek` 均摊时间复杂度为 O(1)，空间复杂度为 O(n)。

## 二、Java 知识点

### 1. Queue、Deque 接口

Java 的 `java.util` 包提供了队列接口：

- `Queue`：普通队列接口，遵循先进先出。
- `Deque`：双端队列接口，支持两端插入和删除，既能实现队列，也能模拟栈。

常用方法：

| Queue | 作用 |
|---|---|
| `offer(e)` | 入队 |
| `poll()` | 出队，空时返回 null |
| `peek()` | 查看队头，空时返回 null |

Deque 还提供 `addFirst()`、`addLast()`、`removeFirst()`、`removeLast()` 等方法。

### 2. 常见队列实现类

- `ArrayDeque`：基于数组，不允许 null，适合实现栈、队列和双端队列。
- `LinkedList`：基于双向链表，同时实现 Queue 和 Deque。
- `PriorityQueue`：优先级队列，默认小顶堆。
- `ArrayBlockingQueue`、`LinkedBlockingQueue`：线程安全的阻塞队列，常用于多线程任务处理。

注意：Queue 和 Deque 是接口，不能直接实例化；ArrayDeque 和 LinkedList 是具体实现类。

### 3. 推荐声明方式

```java
Queue<Integer> queue = new ArrayDeque<>();
Deque<Integer> deque = new ArrayDeque<>();
Deque<Integer> stack = new ArrayDeque<>();
```

面向接口编程，左侧使用接口类型，右侧使用具体实现类，便于后续替换实现。

### 4. Deque 的两种使用方式

作为栈：`push()` 入栈、`pop()` 出栈、`peek()` 查看栈顶。

作为队列：`offerLast()` 入队、`pollFirst()` 出队、`peekFirst()` 查看队头。

### 5. final 修饰引用

本题使用 `private final Deque<Integer>` 声明两个栈。`final` 限制引用重新赋值，但不限制对象内部修改，因此仍然可以执行 `push()`、`pop()` 等操作。

**记忆重点：** Java 刷题优先掌握 Queue、Deque 和 ArrayDeque；普通队列使用 Queue，栈和双端队列优先使用 Deque。

# Java 队列（Queue）知识点总结

## 一、队列的基本概念

队列（Queue）是一种线性数据结构，遵循 **FIFO（First In, First Out，先进先出）** 原则，即先进入队列的元素先被取出。

队列有两个主要位置：
- 队头（Front）：删除和获取元素的位置。
- 队尾（Rear）：添加元素的位置。

基本操作：入队（Enqueue）、出队（Dequeue）、查看队头、判断队列是否为空。

## 二、Java Queue 接口

Java 的 `java.util.Queue` 是队列接口，继承自 `Collection`，不能直接实例化。

常用方法：

| 方法 | 功能 | 队列为空时 |
|---|---|---|
| `offer(e)` | 入队 | 失败返回 false |
| `poll()` | 出队并返回队头 | 返回 null |
| `peek()` | 查看队头，不删除 | 返回 null |
| `add(e)` | 入队 | 抛出异常 |
| `remove()` | 出队 | 抛出异常 |
| `element()` | 查看队头 | 抛出异常 |

推荐使用 `offer()`、`poll()`、`peek()`，避免异常处理。

## 三、常见队列实现类

1. `ArrayDeque`：基于数组实现，不允许 null，效率较高，适合普通队列和双端队列。
2. `LinkedList`：基于双向链表，同时实现 Queue 和 Deque。
3. `PriorityQueue`：优先级队列，默认小顶堆，优先取出最小元素。
4. `ArrayBlockingQueue`：有界阻塞队列，适用于多线程场景。
5. `LinkedBlockingQueue`：链表实现的阻塞队列，常用于生产者消费者模型。

## 四、Deque 双端队列

`Deque`（Double Ended Queue）允许从队头和队尾进行插入、删除。

| 操作 | 队头 | 队尾 |
|---|---|---|
| 添加 | `addFirst()` | `addLast()` |
| 删除 | `removeFirst()` | `removeLast()` |
| 查看 | `peekFirst()` | `peekLast()` |

Deque 既可以作为队列，也可以作为栈：`push()`、`pop()`、`peek()` 分别对应入栈、出栈和查看栈顶。

## 五、刷题建议

```java
Queue<Integer> queue = new ArrayDeque<>();
Deque<Integer> deque = new ArrayDeque<>();
```

普通队列使用 Queue，栈和双端队列优先使用 Deque。注意 `poll()` 和 `peek()` 空时返回 null，而 `remove()` 和 `element()` 空时会抛出异常。队列常用于 BFS 广度优先搜索、层序遍历和任务调度。
