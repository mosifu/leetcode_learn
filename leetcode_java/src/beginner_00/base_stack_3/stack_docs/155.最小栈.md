# LeetCode 155：最小栈

## 一、解题思路（约30%）

本题要求在常数时间内完成入栈、出栈、获取栈顶和获取最小值操作。采用**双栈法**：主栈 `stack` 保存全部元素，辅助栈 `min_stack` 保存当前最小值及其历史变化。

- `push(value)`：主栈直接入栈；如果辅助栈为空，或者新元素小于等于辅助栈顶，则同步入辅助栈。使用 `<=` 是为了正确处理重复的最小值。
- `pop()`：主栈弹出栈顶元素。如果弹出的元素等于辅助栈顶，则辅助栈也同步弹出。
- `top()`：返回主栈顶元素。
- `getMin()`：返回辅助栈顶元素。

例如依次入栈 `-2、0、-3`，辅助栈保存 `-2、-3`。弹出 `-3` 后，辅助栈顶恢复为 `-2`，无需重新遍历主栈。

所有操作均为 O(1)，空间复杂度为 O(n)。

## 二、Java知识点（约70%）

1. **Deque 与 ArrayDeque**：`Deque` 是双端队列接口，`ArrayDeque` 是常用实现。使用 `Deque<Integer> stack = new ArrayDeque<>();` 实现栈，`push()` 入栈、`pop()` 弹出、`peek()` 查看栈顶。`peek()` 在栈为空时返回 `null`，`pop()` 则会抛出异常。

2. **泛型与自动拆箱**：`Deque<Integer>` 使用包装类型 `Integer`，不能直接写 `Deque<int>`。当 `int` 与 `Integer` 比较时，可能发生自动拆箱。若 `peek()` 返回 `null`，拆箱会产生 `NullPointerException`，因此使用 `!stack.isEmpty() && value == stack.peek()`，利用 `&&` 短路特性避免空指针。

3. **final 修饰引用变量**：`private final Deque<Integer> stack;` 表示引用初始化后不能重新指向其他对象，但仍可以通过 `push()`、`pop()` 修改栈内元素。适合本题中初始化后不再更换栈对象的场景。

4. **static 内部类**：`static class MinStack` 是静态内部类，不依赖外部类实例，可以通过 `new MinStack_155.MinStack()` 创建。非静态内部类则需要先创建外部类对象。注意，static 修饰内部类不代表其成员变量和方法也必须是 static。

5. **类与对象**：`MinStack()` 是构造方法，用于初始化两个栈；`push()`、`pop()` 等是实例方法，每个 MinStack 对象拥有独立的栈。

**核心记忆：** 双栈同步维护最小值，使用 `<=` 处理重复最小值；`Deque + ArrayDeque` 实现栈，`peek()` 注意空值与自动拆箱问题。
