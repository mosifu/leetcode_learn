# LeetCode 20：有效的括号

## 一、解题思路（约30%）

本题使用**栈（Stack）+ 哈希表（HashMap）**解决。括号具有后进先出（LIFO）的匹配特点：最后出现的左括号，必须最先与右括号匹配，因此适合使用栈。

1. **建立括号映射**：使用 `HashMap<Character, Character>` 保存左括号与对应右括号的关系，例如 `('(', ')')`。
2. **创建栈**：使用 `Deque<Character> stack = new ArrayDeque<>();` 保存尚未匹配的左括号。
3. **遍历字符串**：通过增强 for 循环逐个读取字符。遇到左括号，就使用 `push()` 入栈；遇到右括号，先判断栈是否为空，再弹出栈顶左括号，通过 Map 查找其对应的右括号，与当前字符比较。
4. **判断最终结果**：遍历结束后，只有栈为空才表示所有左括号都已匹配。

例如 `s = "([])"`：

```text
读取 '(' → 入栈       [(]
读取 '[' → 入栈       [(, []
读取 ']' → 出栈 '['   [(]
读取 ')' → 出栈 '('   []
```

最终栈为空，返回 `true`。如果出现类型不匹配、右括号没有对应左括号，或者遍历结束后栈仍有元素，都返回 `false`。

时间复杂度 O(n)，空间复杂度 O(n)，n 为字符串长度。

## 二、Java 知识点（约70%）

1. **HashMap 与泛型**：`HashMap<Character, Character>` 表示键和值都是 `Character` 类型的映射集合。`put(key,value)` 添加映射，`containsKey(c)` 判断是否存在指定键，`get(key)` 根据键获取对应值。Map 不保证元素顺序，但本题只需要进行括号映射查询。

2. **基本类型与包装类型**：Java 泛型不能直接使用 `char` 等基本类型，因此使用包装类 `Character`。`char` 和 `Character` 之间可以通过自动装箱、自动拆箱转换。

3. **字符串转字符数组**：`s.toCharArray()` 将 String 转换成 `char[]`。字符串本身不可变，转换后得到独立的字符数组。注意 Java 的 `char` 表示 UTF-16 代码单元，不是字节；本题括号均属于单个 char 可以表示的字符。

4. **增强 for 循环**：`for (char c : s.toCharArray())` 依次获取数组中的字符，不需要手动维护下标，适合只关心元素、不需要索引的遍历场景。

5. **Deque 实现栈**：`Deque<Character> stack = new ArrayDeque<>();` 使用接口声明、实现类创建对象。`push(c)` 等价于 `addFirst(c)`，将元素放到队头；`pop()` 等价于 `removeFirst()`，取出并删除栈顶元素；`isEmpty()` 判断栈是否为空。使用 Deque 代替旧的 Stack 类通常更推荐。

6. **短路逻辑运算符**：`stack.isEmpty() || !map_str.get(stack.pop()).equals(c)` 中，`||` 具有短路特性：左侧为 true 时，右侧不执行。因此栈为空时不会调用 `pop()`，避免空栈异常。`!` 表示逻辑取反，`equals()` 用于比较对象内容。

7. **边界判断**：最后的 `return stack.isEmpty()` 很关键，它可以识别 `"((("` 这种只有左括号、没有闭合的情况。只判断遍历过程中是否匹配是不够的，还必须检查剩余左括号。

**补充注意**：本题给定的字符只有三种左括号和三种右括号，因此 `else` 分支可以直接视为右括号处理。如果字符范围扩大，则需要额外判断当前字符是否合法。
