# LeetCode 394：字符串解码

## 一、解题思路（约30%）

采用**双栈 + StringBuilder**解决嵌套解码问题。定义数字栈 `int_deq` 保存每层括号的重复次数，字符串栈 `str_deq` 保存进入左括号前已构建的字符串，`cur_str` 保存当前正在解码的字符串，`num` 累积数字。

遍历字符串时：
1. 遇到字母：使用 `append()` 追加到当前字符串。
2. 遇到数字：通过 `num = num * 10 + (c - '0')` 累积重复次数，支持多位数。
3. 遇到 `[`：数字和当前字符串分别入栈，重置 `num` 和 `cur_str`，开始构建内部字符串。
4. 遇到 `]`：弹出重复次数和之前的字符串，将当前字符串重复指定次数后追加到之前的字符串，再更新 `cur_str`。

利用栈后进先出特性，先完成内层解码，再逐层向外拼接。最终返回 `cur_str.toString()`。

时间复杂度为 \(O(n+L)\)，空间复杂度为 \(O(n+L)\)，其中 n 为输入长度，L 为解码后字符串长度。

## 二、Java 知识点（约70%）

### 1. String：不可变字符串

`String` 是引用类型，创建后内容不可修改。执行 `str = str + "abc"` 时，并非修改原对象，而是创建新字符串并让引用指向新对象。

常用方法：`length()` 获取长度、`charAt()` 获取字符、`substring()` 截取、`equals()` 比较内容、`toCharArray()` 转字符数组、`repeat(n)` 重复字符串。`repeat()` 从 Java 11 开始提供，JDK 17 可以使用。

### 2. StringBuilder：可变字符串

`StringBuilder` 可以直接修改对象内容，适合频繁拼接字符串。常用方法：

- `append(x)`：末尾追加内容。
- `insert(i,x)`：指定位置插入。
- `delete(a,b)`：删除指定范围。
- `reverse()`：反转字符串。
- `length()`、`charAt()`：获取长度和字符。
- `toString()`：转换为 String。

本题使用 `append()` 拼接解码结果，避免频繁创建中间字符串。`StringBuilder` 是可变对象，赋值传递的是对象引用，因此 `str_deq.push(cur_str)` 保存原对象后，再执行 `cur_str = new StringBuilder()` 不会清空栈中保存的字符串。

### 3. StringBuffer：线程安全的可变字符串

`StringBuffer` 与 `StringBuilder` 用法基本相同，区别在于其主要修改方法带有同步机制，适合多线程共享修改同一个对象的场景，但通常性能开销更大。

| 类型 | 可变性 | 线程安全 | 典型用途 |
|---|---|---|---|
| String | 不可变 | 对象不可变 | 普通字符串 |
| StringBuilder | 可变 | 不保证 | 高频拼接 |
| StringBuffer | 可变 | 主要方法同步 | 多线程共享修改 |

### 4. 其他相关语法

- `Character.isLetter(c)`、`isDigit(c)`：判断字母和数字。
- `c - '0'`：数字字符转换为整数。
- `Deque.push()`、`pop()`：入栈和出栈。
- `String.valueOf()`：将其他类型转换为字符串。
- `String.repeat(count)`：重复字符串指定次数。

**记忆重点：** 普通字符串使用 String，动态拼接优先使用 StringBuilder，多线程共享修改时考虑 StringBuffer。嵌套解码则利用双栈保存每层状态。
