# LeetCode 227：基本计算器 II

## 一、解题思路（约30%）

本题需要考虑四则运算优先级。采用栈保存计算结果，将乘除法提前计算，加减法暂时保留，最后对栈内元素求和。

1. **遍历与数字拼接**：遍历字符数组，遇到数字时，通过 `num = num * 10 + (current - '0')` 将连续数字拼接成完整整数。
2. **运算符处理**：当遇到非数字字符或遍历到最后一个字符时，根据上一个运算符 `pre_sign` 执行计算：
    - `+`：将当前数字入栈。
    - `-`：将当前数字取负后入栈。
    - `*`：弹出栈顶元素，与当前数字相乘，再将结果入栈。
    - `/`：弹出栈顶元素，与当前数字相除，再将结果入栈。
3. **更新状态**：将当前字符保存为新的运算符，清零 `num`，继续遍历。
4. **汇总结果**：遍历结束后，栈中只剩加减项，使用 Stream 求和得到最终结果。

例如 `3+5/2`：先将 `3`、`5` 入栈，遇到 `/` 后计算 `5/2=2`，最终栈中为 `3、2`，求和得到 `5`。

时间复杂度 O(n)，空间复杂度 O(n)。

## 二、Java 知识点（约70%）

1. **字符串处理**：`s.replace(" ", "")` 删除空格并返回新字符串，原字符串不变；`toCharArray()` 将字符串转换为 `char[]`；`length` 获取数组长度。

2. **字符遍历**：通过 `chars[i]` 获取当前字符，`Character.isDigit(current)` 判断是否为数字字符。`char` 是基本类型，使用 `==` 比较运算符；字符使用单引号。

3. **字符转数字**：`current - '0'` 利用数字字符编码连续的特点，将字符转换为整数。`num * 10 + 当前数字` 实现多位数拼接。

4. **运算符与状态变量**：`char pre_sign = '+'` 保存上一个运算符。使用 `==` 判断字符运算符，而不是 `equals()`。`i == chars_len - 1` 用于处理最后一个数字，避免遗漏。

5. **Deque 栈操作**：`Deque<Integer>` 配合 `ArrayDeque<>` 实现栈。`push()` 入栈，`pop()` 弹出栈顶并返回元素。乘除法直接修改栈顶对应的计算结果，从而保证优先级。

6. **整数除法**：Java 整数相除会向 0 截断，例如 `-7 / 2 == -3`，符合本题要求。

7. **Stream 求和**：`stack.stream().mapToInt(Integer::intValue).sum()` 将 Integer 流转换为 int 流并求和，不会改变原栈。

**核心记忆：** 加减法入栈，乘除法立即计算；通过保存上一个运算符，实现运算优先级，无需构建完整表达式树。
