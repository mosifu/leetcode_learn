# 105. 从前序与中序遍历序列构造二叉树

## 一、核心解题思路

题目给出二叉树的前序遍历 `preorder` 和中序遍历 `inorder`，要求还原二叉树。

- **前序遍历：根 → 左 → 右**，因此当前子树的第一个元素就是根节点。
- **中序遍历：左 → 根 → 右**，因此找到根节点的位置后，可以将数组划分为左、右子树。

两种遍历结合，就能确定每个节点及其左右子树的结构。

## 二、方法一：递归 + 数组复制

1. 判断前序数组是否为空，若为空则返回 `null`。
2. 取 `preorder[0]` 创建当前根节点。
3. 遍历中序数组，找到根节点的索引 `i`。
4. 根据左右子树节点数量，使用 `Arrays.copyOfRange()` 截取对应的前序和中序数组。
5. 递归构建左右子树，分别赋值给 `root.left` 和 `root.right`。

这种方法直观，但每次递归都会创建新数组，并且查找根节点需要遍历中序数组，时间复杂度最坏为 O(n²)。

## 三、方法二：递归 + HashMap + 下标区间（重点）

这是更高效的实现方式，核心是**不再复制数组，而是通过四个边界下标表示当前子树的遍历范围**。

### 1. 建立 HashMap

首先遍历中序数组，将节点值与对应索引保存为键值对：

`inorderMap.put(inorder[i], i)`

这样就能通过根节点值快速找到它在中序数组中的位置，平均查询时间为 O(1)。

### 2. 定义递归参数

使用四个边界表示当前子树：

- `pre_left`、`pre_right`：当前子树在前序数组中的范围。
- `in_left`、`in_right`：当前子树在中序数组中的范围。

当 `pre_left > pre_right` 时，说明当前子树为空，返回 `null`。

### 3. 确定根节点和左子树长度

当前根节点为 `preorder[pre_left]`，通过 HashMap 获取它在中序数组中的位置 `idx`。

左子树节点数量：

`left_size = idx - in_left`

### 4. 划分左右子树区间

根据前序遍历和中序遍历的特点：

| 区域 | 前序数组区间 | 中序数组区间 |
|---|---|---|
| 左子树 | `[pre_left+1, pre_left+left_size]` | `[in_left, idx-1]` |
| 右子树 | `[pre_left+left_size+1, pre_right]` | `[idx+1, in_right]` |

分别递归构建左右子树，最终返回当前根节点。

### 5. 复杂度分析

- 时间复杂度：O(n)，HashMap 建立和递归构建均为 O(n)。
- 空间复杂度：O(n)，HashMap 和递归调用栈共同占用空间。

## 四、关键知识点

1. **递归区间划分**：递归时不必创建新数组，可以通过左右边界控制当前处理范围。
2. **左闭右闭区间**：本题所有区间均采用 `[left, right]`，因此空区间判断为 `left > right`。
3. **区间长度计算**：通过中序根节点位置减去当前左边界，得到左子树节点数量。
4. **HashMap 优化查找**：将中序遍历中的线性查找优化为平均 O(1) 查询。
5. **避免数组复制**：使用索引传递子问题范围，减少额外数组创建和复制开销。

**总结：** 方法二最重要的不是 HashMap，而是利用 `left_size` 将前序和中序遍历区间同步划分。掌握这种下标区间递归思想，可以迁移到其他二叉树构造和分治类题目中。
