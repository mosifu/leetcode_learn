# 236. 二叉树的最近公共祖先

## 一、解题思路：递归 + 深度优先搜索（DFS）

本题采用**后序遍历思想**，从根节点开始递归搜索左右子树，根据左右子树的返回结果判断最近公共祖先。

1. **递归终止条件**：当 `root == null` 时，说明当前路径没有找到目标节点，返回 `null`；当 `root == p` 或 `root == q` 时，说明找到目标节点，直接返回当前节点。这里也处理了一个目标节点是另一个目标节点祖先的情况。
2. **递归搜索左子树**：调用 `lowestCommonAncestor(root.left, p, q)`，获取左子树的搜索结果。
3. **递归搜索右子树**：调用 `lowestCommonAncestor(root.right, p, q)`，获取右子树的搜索结果。
4. **合并递归结果**：
    - 左右结果都不为 `null`：说明 p、q 分别位于当前节点两侧，当前节点就是最近公共祖先。
    - 只有一侧不为 `null`：说明目标节点在这一侧，直接返回该结果。
    - 两侧都为 `null`：说明当前子树没有找到目标节点，返回 `null`。

## 二、递归过程示意

以 `p = 5、q = 4` 为例：

```text
             3
           /   \
          5     1
         / \   / \
        6   2 0   8
           / \
          7   4

       节点5                  节点1
         |                   /    \
      命中p                 0      8
         |                   \    /
       返回5                都返回null
         \                    /
          \                  /
           节点3收到 left=5，right=null
                       |
                    返回5
                       |
                  最近公共祖先
```

## 三、相关递归知识

- **递归终止条件（Base Case）**：负责结束递归，避免无限调用。
- **递归调用（Recursive Case）**：将原问题拆分成左、右子树的同类问题。
- **递归返回值**：本题返回 `TreeNode`，不仅表示是否找到目标节点，还携带找到的节点信息，便于向上层传递结果。
- **后序遍历**：先处理左子树，再处理右子树，最后根据两个子树的结果处理当前节点。
- **递归回溯**：子节点完成搜索后，结果逐层返回父节点，父节点再根据返回值作出判断。

## 四、复杂度分析

- **时间复杂度：O(n)**，最坏情况下需要遍历所有节点。
- **空间复杂度：O(h)**，递归调用栈最多占用树高 h 的空间，最坏为 O(n)，平衡树约为 O(log n)。

**核心思想：通过递归返回值传递搜索结果，在回溯过程中确定最近公共祖先。**
