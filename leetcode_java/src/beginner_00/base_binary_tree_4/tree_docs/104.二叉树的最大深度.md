# 104. 二叉树的最大深度

## 一、解题思路：递归（后序遍历）

采用**递归 + 后序遍历**的方式，分别计算左、右子树的最大深度，再取较大值并加上当前根节点的深度。

1. **确定递归终止条件**：当 `root == null` 时，说明已经到达空节点，返回 `0`。
2. **递归计算左子树**：调用 `maxDepth(root.left)`，得到左子树的最大深度。
3. **递归计算右子树**：调用 `maxDepth(root.right)`，得到右子树的最大深度。
4. **合并结果**：使用 `Math.max(left, right) + 1`，取左右子树较大的深度，再加上当前根节点。

**递归过程示意：**

```text
             3
           /   \
          9     20
               /  \
              15   7

          9          15、7
          |             |
        返回1          返回1
                       |
                  节点20返回2
          \             /
           \           /
             节点3返回3

          最大深度 = 3
```

## 二、相关 Java 知识

- **递归方法**：方法在自身内部调用自身。每次调用都会创建独立的栈帧，保存当前调用的参数和局部变量；递归返回时逐层向上执行。
- **递归终止条件**：必须设置，否则递归无法正常结束。本题中空节点返回 `0`，既能终止递归，也能作为深度计算的基础。
- **`Math.max(a, b)`**：Java 的 `Math` 类提供的静态方法，返回两个数中的较大值。本题用于比较左右子树深度。
- **`Objects.isNull(obj)`**：判断对象是否为 `null`，等价于 `obj == null`。属于 `java.util.Objects` 类的静态方法。
- **后序遍历**：先处理左子树，再处理右子树，最后处理当前节点。本题需要先得到左右子树的结果，再计算当前节点深度，因此符合后序遍历思想。

## 三、复杂度分析

- **时间复杂度：O(n)**，每个节点只访问一次，`n` 为节点总数。
- **空间复杂度：O(h)**，递归调用栈最多保存树高 `h` 层；最坏情况下退化为链表，空间复杂度为 O(n)。
