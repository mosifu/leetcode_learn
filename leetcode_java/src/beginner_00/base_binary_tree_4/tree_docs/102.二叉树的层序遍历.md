# 102. 二叉树的层序遍历

## 一、解题思路：广度优先搜索（BFS）

本题使用**队列 + 广度优先搜索**，按照从上到下、从左到右的顺序逐层遍历二叉树。

1. **初始化队列**：判断根节点是否为空，若为空直接返回空列表；否则将根节点加入队列。
2. **逐层遍历**：当队列不为空时，记录当前队列长度 `n`，表示当前层的节点数量。
3. **处理当前层**：循环 `n` 次，每次从队头取出一个节点，将其值加入当前层列表 `curr`。
4. **加入下一层节点**：分别判断当前节点的左、右子节点是否为空，若不为空则加入队尾。
5. **保存当前层结果**：将 `curr` 加入最终结果 `res`，继续处理下一层，直到队列为空。

## 二、遍历过程示意

```text
       3                  9、20                 15、7
      / \                  /  \                 /  \
     9   20               15   7               null null

队列：[3]             队列：[9,20]           队列：[15,7]
结果：[[3]]            结果：[[3],[9,20]]     最终结果：
                                             [[3],[9,20],[15,7]]
```

## 三、相关 Java 知识点

- **Queue / Deque**：队列遵循 FIFO（先进先出）。本题使用 `Deque<TreeNode>` 接口和 `ArrayDeque` 实现队列。
- **offerLast()**：从队尾添加元素；**pollFirst()**：从队头取出并删除元素。两者配合实现普通队列。
- **size()**：获取当前队列元素数量。每轮开始时保存 `n`，确保只处理当前层节点，新加入的子节点留到下一轮。
- **ArrayList**：`List<List<Integer>>` 表示二维列表，外层保存每层结果，内层保存该层节点值。
- **独立 if 判断**：左右子节点必须分别判断，不能使用 `if...else if`，否则可能遗漏其中一个子节点。
- **Objects.isNull() / Objects.nonNull()**：分别判断对象是否为空或非空，等价于 `== null` 和 `!= null`。

## 四、复杂度分析

- **时间复杂度：O(n)**，每个节点只入队、出队一次。
- **空间复杂度：O(n)**，队列最多保存一层节点，结果列表也需要保存全部节点。

**核心思想：利用队列先进先出的特性，通过固定每轮处理的节点数量，实现逐层遍历。**
