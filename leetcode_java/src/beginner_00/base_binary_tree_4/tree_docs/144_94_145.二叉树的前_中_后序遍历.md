# LeetCode 144、94、145：二叉树前序、中序、后序遍历

## 一、解题思路

二叉树的深度优先遍历（DFS）分为三种，核心区别是访问根节点的时机：

| 遍历方式 | 访问顺序 | 记忆方式 |
|---|---|---|
| 前序遍历 | 根 → 左 → 右 | 根在前 |
| 中序遍历 | 左 → 根 → 右 | 根在中 |
| 后序遍历 | 左 → 右 → 根 | 根在后 |

三种遍历均使用递归实现：

1. **递归终止条件**：当前节点为 null，直接返回空列表。
2. **递归过程**：按照对应顺序访问根节点、左子树和右子树。
3. **结果汇总**：使用 `add()` 添加单个节点值，使用 `addAll()` 合并左右子树的遍历结果。

前、中、后序遍历的区别仅在于根节点访问的位置。

## 二、二叉树构建

本地测试时，可以使用 List 模拟 LeetCode 的层序数组输入，通过队列构建二叉树。

示例输入：

`[1,2,3,4,5,null,8,null,null,6,7,9]`

构建结果：

```text
          1
        /   \
       2     3
      / \     \
     4   5     8
        / \   /
       6   7 9
```

**构建原理：**

- 使用 Queue 保存等待处理的父节点。
- 每次通过 `poll()` 取出一个父节点。
- 按顺序读取左、右孩子的值。
- 非 null 时创建子节点，并通过 `offer()` 加入队列。
- null 表示该位置没有节点，但仍然占用一个输入位置。

### 构建过程：横向阶段图

```text
阶段             初始化          处理节点1         处理节点2         处理节点3         最终结果

treeRoot          1                1                 1                 1                1
                                   / \               / \               / \             / \
                                  2   3             2   3             2   3           2   3
                                                   / \                 \             / \   \
                                                  4   5                 8           4   5   8
                                                                       /               / \ /
                                                                      9               6  7 9

node                              1                 2                 3
queue            [1]             [2,3]             [3,4,5]           [4,5,8]
------------------------------------------------------------------------------------------------>
```

**root 与 node 的区别：**

```text
阶段1：初始化       阶段2：处理节点1       阶段3：处理节点2

treeRoot           treeRoot               treeRoot
   |                  |                      |
   v                  v                      v
  [1]                [1]                    [1]
                    /   \                  /   \
                   2     3                2     3
                   ^                       ^
                   |                       |
                  node                    node
------------------------------------------------------------------------------------------------>
```

`treeRoot` 始终保存根节点引用；`node` 是循环中的临时变量，不断指向当前处理的节点。修改 `node` 所指向对象的左右孩子，就是在修改整棵树的结构，因此最后返回 `treeRoot` 即可获得完整二叉树。

## 三、Java 核心知识点

1. **面向接口编程**：`List`、`Queue` 是接口，`ArrayList`、`ArrayDeque` 是实现类。左边使用接口，右边创建实现类。
2. **Queue 队列**：先进先出（FIFO）。`offer()` 从队尾添加，`poll()` 从队头取出并删除。
3. **List 方法**：`add()` 添加单个元素，`addAll()` 批量合并集合元素。
4. **Objects.isNull()**：判断对象是否为 null，等价于 `obj == null`。
5. **Arrays.asList()**：将元素转换为 List，允许包含 null；`List.of()` 不允许 null。
6. **对象引用**：多个变量可以指向同一个对象，修改对象属性会影响该对象的整体结构。
7. **递归**：每次调用都有独立的栈帧，递归返回时逐层继续执行；需要明确终止条件和递归顺序。

## 四、复杂度分析

设节点数量为 n：

| 操作 | 时间复杂度 | 空间复杂度 |
|---|---|---|
| 二叉树构建 | O(n) | O(n) |
| 前序遍历 | O(n) | O(n) |
| 中序遍历 | O(n) | O(n) |
| 后序遍历 | O(n) | O(n) |

每个节点只访问一次。递归栈最坏需要 O(n) 空间，结果列表需要 O(n) 空间。

**核心总结：** 二叉树构建使用队列实现 BFS，三种深度优先遍历使用递归实现 DFS。掌握队列的先进先出、递归终止条件以及根节点的访问顺序，就能理解这三种遍历。
