# 98. 验证二叉搜索树

## 一、题目核心

二叉搜索树（BST）需要满足：

1. 左子树所有节点的值严格小于当前节点。
2. 右子树所有节点的值严格大于当前节点。
3. 左右子树也必须分别满足二叉搜索树的规则。

**注意：不能只比较当前节点与左右孩子，还必须考虑所有祖先节点对当前节点的取值限制。**

## 二、解题思路一：递归 + 上下界限制

这是第一种方法，也是最直观的范围校验法。

**核心思想：** 递归过程中，为每个节点传递允许的最小值 `minLimit` 和最大值 `maxLimit`，判断当前节点是否处于合法范围内。

1. 递归终止：当前节点为 `null`，说明没有违反规则，返回 `true`。
2. 递归左子树：左子树的最大限制更新为当前节点值，最小限制保持不变。
3. 递归右子树：右子树的最小限制更新为当前节点值，最大限制保持不变。
4. 判断当前节点是否满足 `minLimit < curNode.val < maxLimit`，并且左右子树均合法。

**代码特点：** 先递归左右子树，再判断当前节点。即使当前节点已经越界，也可能继续执行不必要的递归。

## 三、解题思路二：递归 + 提前终止

这是第一种方法的优化版本，也是你最终采用的方法。

**核心思想不变，区别在于先检查当前节点是否合法，再递归左右子树。**

1. 当前节点为空，返回 `true`。
2. 如果 `curNode.val <= minLimit` 或 `curNode.val >= maxLimit`，立即返回 `false`。
3. 递归检查左子树，如果返回 `false`，直接结束。
4. 递归检查右子树，如果返回 `false`，直接结束。
5. 左右子树均合法，返回 `true`。

这种写法利用了 `if` 判断提前终止，避免发现错误后仍然遍历剩余节点。

**上下界传递示意：**

```text
             5
           /   \
          1     7
               / \
              6   8

节点5：( -∞, +∞ )
节点1：( -∞, 5 )
节点7：( 5, +∞ )
节点6：( 5, 7 )
节点8：( 7, +∞ )
```

## 四、解题思路三：中序遍历 + 前驱节点比较

**核心思想：** 二叉搜索树进行中序遍历（左、根、右），得到的节点值必须严格递增。

1. 递归遍历左子树。
2. 将当前节点值与前一个访问节点的值 `pre` 比较。
3. 如果 `curNode.val <= pre`，说明不是严格递增，返回 `false`。
4. 更新 `pre = curNode.val`。
5. 递归遍历右子树。

例如：

```text
       5
      / \
     1   7
        / \
       6   8

中序遍历：1 → 5 → 6 → 7 → 8
```

注意：这里的 `pre` 必须是成员变量，才能在不同递归调用之间共享前一个节点的值。每次重新调用验证方法时，也需要将它重置为 `Long.MIN_VALUE`，否则重复使用同一个对象可能产生错误。

## 五、相关 Java 知识

1. **`Long` 与 `long`**：`long` 是基本数据类型，`Long` 是包装类。上下界使用 `long` 可以覆盖所有 `int` 节点值，避免 `Integer.MIN_VALUE` 和 `Integer.MAX_VALUE` 的边界问题。推荐使用 `long minLimit, long maxLimit`，减少不必要的装箱拆箱。
2. **`Long.MIN_VALUE / Long.MAX_VALUE`**：分别表示 `long` 类型的最小值和最大值，可作为初始上下界。
3. **递归返回值与短路判断**：`&&` 具有短路特性，左侧为 `false` 时不会继续计算右侧。可以利用这一特点提前终止递归。
4. **成员变量与局部变量**：`pre` 是成员变量，所有递归调用共享同一个值；局部变量则属于当前方法调用，各次递归互不影响。
5. **中序遍历**：BST 的中序遍历结果严格递增，这是验证二叉搜索树的重要性质。
6. **`Objects.isNull()`**：判断对象是否为 `null`，等价于 `curNode == null`。

## 六、复杂度分析与总结

| 方法 | 时间复杂度 | 空间复杂度 |
|---|---|---|
| 方法一：上下界递归 | O(n) | O(h) |
| 方法二：提前终止递归 | 最坏 O(n) | O(h) |
| 方法三：中序遍历 | 最坏 O(n) | O(h) |

其中，`n` 是节点数量，`h` 是树的高度，空间主要来自递归调用栈。

**三种方法的区别：**

- 方法一：通过上下界判断节点是否合法。
- 方法二：在方法一基础上增加提前终止，减少不必要的递归。
- 方法三：利用 BST 中序遍历严格递增的性质，通过比较前驱节点判断合法性。

**推荐掌握方法二和方法三：** 方法二适合练习递归参数传递和上下界约束；方法三则帮助理解二叉搜索树与中序遍历之间的重要联系。
