# 102. 二叉树的层序遍历

## 一、解题思路：BFS + 队列

层序遍历要求从上到下、从左到右逐层访问二叉树，因此使用广度优先搜索（BFS），借助队列实现先进先出的访问顺序。

1. **判断空树**：如果 `root is None`，直接返回空列表 `[]`。
2. **初始化队列**：使用 `deque()` 创建双端队列，将根节点加入队列，作为遍历起点。
3. **逐层遍历**：使用 `while queue` 判断队列是否为空。每轮开始通过 `n = len(queue)` 记录当前层的节点数量。
4. **处理当前层**：循环 `n` 次，每次从队头取出一个节点，记录节点值，并将其非空左、右子节点依次加入队尾。
5. **保存结果**：当前层处理完成后，将 `curr_level` 加入结果列表，直到所有节点遍历完毕。

**关键点：** `n = len(queue)` 必须在每层循环开始时确定。因为遍历过程中会将下一层节点加入队列，固定 `n` 才能避免提前处理下一层节点。

## 二、Python 队列知识

- `from collections import deque`：导入双端队列，适合实现队列。
- `deque()`：创建空队列。
- `append(x)`：从队尾添加元素。
- `popleft()`：从队头删除并返回元素，实现先进先出（FIFO）。
- `len(queue)`：获取当前队列元素数量。
- `while queue`：利用空容器为 False 的特性，队列非空时持续遍历。

相比使用 `list` 的 `pop(0)`，`deque.popleft()` 的时间复杂度为 O(1)，效率更高。

## 三、复杂度分析

- 时间复杂度：O(n)，每个节点入队、出队各一次。
- 空间复杂度：O(n)，队列最坏需要存储 O(n) 个节点，结果列表也需要 O(n) 空间。

**核心思想：** 队列负责控制节点访问顺序，固定每轮开始时的队列长度负责区分层级，两者结合即可完成二叉树的层序遍历。
