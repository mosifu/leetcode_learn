# 105. 从前序与中序遍历构造二叉树

## 一、解题思路

前序遍历顺序为「根、左、右」，中序遍历顺序为「左、根、右」。利用前序遍历确定根节点，再根据根节点在中序遍历中的位置划分左右子树，递归构建。

### 方法一：递归 + 列表切片

1. 前序遍历第一个元素 `preorder[0]` 就是当前根节点。
2. 使用 `inorder.index(root_val)` 找到根节点在中序遍历中的位置。
3. 根节点左边是左子树，右边是右子树。
4. 根据左右子树的节点数量，分别切分前序和中序数组，递归构建左右子树。

该方法直观，但每次切片都会创建新列表，且 `index()` 需要线性查找，最坏时间复杂度为 O(n²)。

### 方法二：递归 + 哈希表 + 索引边界

先使用字典保存中序遍历中每个节点值对应的索引：`{val: index for index, val in enumerate(inorder)}`，避免递归过程中重复查找。

递归函数 `solver(pre_left, pre_right, in_left, in_right)` 使用四个索引，分别表示前序和中序遍历当前子树的左右边界，边界均包含在内。

**核心计算：**

- 根节点：`preorder[pre_left]`。
- 根节点在中序中的位置：`root_idx`。
- 左子树节点数量：`left_size = root_idx - in_left`。
- 前序左子树：`[pre_left+1, pre_left+left_size]`。
- 前序右子树：`[pre_left+left_size+1, pre_right]`。
- 中序左子树：`[in_left, root_idx-1]`。
- 中序右子树：`[root_idx+1, in_right]`。

## 二、第二种方法的索引推导

以示例为例：

```text
preorder: [3, 9, 20, 15, 7]
inorder : [9, 3, 15, 20, 7]
```

根节点为 3，在中序中的索引为 1，因此 `left_size = 1 - 0 = 1`。

```text
前序：[3 | 9 | 20, 15, 7]
       根   左       右

中序：[9 | 3 | 15, 20, 7]
       左   根      右
```

对应索引范围：

```text
前序索引：  0     1          2          3          4
前序数组： [3]   [9]        [20]       [15]       [7]
           根    左子树      右子树

中序索引：  0     1          2          3          4
中序数组： [9]   [3]        [15]       [20]       [7]
           左    根          右子树

左子树：pre[1,1]，in[0,0]
右子树：pre[2,4]，in[2,4]
```

为什么这样设置？因为前序遍历中，根节点后面的 `left_size` 个节点属于左子树，剩余节点属于右子树；中序遍历则直接根据根节点的位置划分左右范围。

## 三、Python 知识与复杂度

- `enumerate(inorder)`：同时获取元素及其索引。
- 字典推导式：快速建立节点值到索引的映射。
- `preorder[0]`：通过索引获取根节点，不需要删除数组元素。
- `pre_left > pre_right`：当前区间为空，递归终止，返回 `None`。

方法一最坏时间复杂度 O(n²)，方法二时间复杂度 O(n)，哈希表空间复杂度 O(n)，递归栈空间复杂度 O(h)。

**核心思想：** 前序确定根节点，中序确定左右子树的节点数量与范围；第二种方法通过索引边界传递子问题，避免列表切片和重复查找。
