# 236. 二叉树的最近公共祖先

## 一、解题思路：递归 + 后序遍历

本题使用后序遍历，递归检查当前节点的左右子树，并向上返回三个信息：当前子树是否包含 `p`、是否包含 `q`、是否已经找到最近公共祖先。

**递归过程：**

1. **终止条件**：如果 `node is None`，说明当前为空节点，返回 `(False, False, None)`。
2. **递归左右子树**：分别调用 `dfs(node.left)` 和 `dfs(node.right)`，获取左右子树的信息。
3. **判断节点是否存在**：当前子树包含 `p`，可能是左子树包含、右子树包含或当前节点就是 `p`，`q` 同理。
4. **确定最近公共祖先**：
   - 如果右子树已经找到最近公共祖先，直接返回 `right_x`。
   - 否则，如果左子树已经找到，返回 `left_x`。
   - 如果左右子树都没有找到，但当前子树同时包含 `p` 和 `q`，那么当前节点就是最近公共祖先。
5. 返回三个信息，继续向上递归。

## 二、递归思想与关键理解

本题采用**后序遍历（左、右、根）**，因为必须先获取左右子树的信息，才能判断当前节点是否为最近公共祖先。

递归函数通过元组同时返回多个信息，实现子问题结果向上传递。需要特别注意：`cur_has_p` 和 `cur_has_q` 都为 True，并不意味着当前节点就是最近公共祖先，因为可能已经在某个子树中找到了更深的公共祖先。因此，必须优先保留左右子树已经找到的结果，避免被更高层节点覆盖。

**核心思想：子树先解决问题，父节点优先继承子树已经得到的答案；只有子树尚未找到答案时，才判断当前节点是否为最近公共祖先。**

## 三、复杂度分析

- 时间复杂度：O(n)，每个节点最多访问一次。
- 空间复杂度：O(h)，主要来自递归调用栈，h 为树的高度，最坏为 O(n)。需要注意，极度倾斜的树可能触发 Python 递归深度限制。
