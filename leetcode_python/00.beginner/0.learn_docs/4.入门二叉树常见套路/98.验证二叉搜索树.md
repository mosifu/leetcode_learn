# 98. 验证二叉搜索树

## 一、解题思路

二叉搜索树（BST）要求：左子树所有节点的值严格小于当前节点，右子树所有节点的值严格大于当前节点，并且左右子树本身也必须是 BST。注意，不能只比较当前节点与左右孩子，还要考虑祖先节点对整棵子树的限制。

### 方法一：递归 + 上下界限制（后序遍历）

定义递归函数 `dfs(node, min_limit, max_limit)`，传入当前节点及其允许的最小、最大值范围。

- 空节点返回 `True`。
- 左子树继承当前节点的最小限制，将最大限制更新为 `node.val`。
- 右子树继承当前节点的最大限制，将最小限制更新为 `node.val`。
- 最后判断左右子树是否都是 BST，以及当前节点是否满足 `min_limit < node.val < max_limit`。

初始范围使用负无穷和正无穷。该方法先检查左右子树，再判断当前节点，属于后序遍历思想。

### 方法二：递归 + 上下界限制（前序遍历）

与方法一使用相同的上下界规则，但先判断当前节点是否合法。如果不满足 `node.val <= min_limit or node.val >= max_limit`，立即返回 `False`；否则继续递归左右子树。

这种写法可以提前剪枝：一旦发现非法节点，就不必继续遍历剩余节点。逻辑更直接。

### 方法三：中序遍历 + 前驱节点比较

BST 的中序遍历顺序是左、根、右，得到的节点值必然严格递增。

使用变量 `pre` 保存前一个访问节点的值，初始为负无穷。遍历时，如果 `node.val <= pre`，说明序列不再严格递增，返回 `False`；否则更新 `pre = node.val`，继续遍历右子树。

## 二、Python 知识点

- `float('inf')` 和 `-float('inf')`：分别表示正无穷和负无穷，可作为初始边界，避免节点值范围带来的限制。
- `nonlocal pre`：用于在嵌套函数中修改外层函数的局部变量。这里 `pre` 需要随着中序遍历不断更新。
- `and`：多个条件必须全部成立才返回 True。
- `return False`：提前结束递归，减少不必要的遍历。
- `node is None`：判断节点是否为空。

## 三、复杂度分析

三种方法的时间复杂度均为 O(n)，最坏情况下需要访问所有节点；递归栈空间复杂度为 O(h)，h 为树的高度，最坏为 O(n)。

**核心总结：** 方法一、二通过上下界保证每个节点满足所有祖先的约束；方法三利用 BST 中序遍历严格递增的性质，通过比较前驱节点验证合法性。

## 四、三种方法的对比与补充

| 方法 | 遍历顺序 | 核心判断 | 特点 |
|---|---|---|---|
| 方法一：上下界递归 | 左→右→根（后序） | 最后检查当前节点是否满足取值范围 | 自底向上汇总左右子树结果 |
| 方法二：上下界递归 | 根→左→右（前序） | 先检查当前节点是否合法 | 可以提前剪枝，减少不必要的递归 |
| 方法三：中序遍历 | 左→根→右 | 当前节点值必须大于前一个节点值 | 利用 BST 中序遍历结果严格递增的性质 |

### 方法一与方法二的区别

两种方法使用相同的上下界限制，区别在于判断顺序：

- 方法一先递归左右子树，再判断当前节点，属于后序遍历思想。
- 方法二先判断当前节点，如果不满足上下界，立即返回 `False`，再递归左右子树，属于前序遍历思想。

方法二可以提前终止无效分支，代码通常更加直观。

### 方法三的代码优化

第三种方法只需要通过中序遍历比较当前节点与前一个节点的值，不需要传递上下界参数。因此可以将递归函数简化为：

```python
def dfs(node: TreeNode | None) -> bool:
    if node is None:
        return True

    if not dfs(node.left):
        return False

    nonlocal pre
    if node.val <= pre:
        return False

    pre = node.val

    if not dfs(node.right):
        return False

    return True
```

其中 `nonlocal pre` 用于修改外层函数中的变量，使 `pre` 能够在整个递归过程中持续保存上一个访问节点的值。

**学习重点：** 三种方法虽然遍历顺序不同，但都是利用递归逐步验证 BST 的性质。前两种从节点取值范围入手，第三种从中序遍历结果入手。理解这两种验证角度，比记住某一种代码写法更重要。
