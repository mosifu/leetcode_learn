# 二叉树前序(144)、中序(94)、后序(145)遍历

## 一、二叉树遍历的核心思路

二叉树由根节点、左子树和右子树组成。遍历的核心是按照指定顺序访问每个节点。前序、中序、后序遍历都属于深度优先搜索（DFS），采用递归实现。

三种遍历的区别在于**访问根节点的时机**：

| 遍历方式 | 顺序 | 访问节点时机 |
|---|---|---|
| 前序遍历 | 中 → 左 → 右 | 先访问根节点 |
| 中序遍历 | 左 → 中 → 右 | 左子树遍历完成后 |
| 后序遍历 | 左 → 右 → 中 | 左右子树遍历完成后 |

## 二、递归解题思路

三种遍历都采用相同的递归框架：

1. 创建结果列表 `res`，用于保存遍历结果。
2. 定义内部递归函数 `f(root)`，处理当前节点。
3. 设置递归终止条件：如果 `root is None`，说明当前节点为空，直接 `return`。
4. 根据遍历顺序，将 `res.append(root.val)` 放在不同位置。
5. 分别递归处理左子树 `f(root.left)` 和右子树 `f(root.right)`。
6. 调用 `f(root)` 启动递归，最后返回 `res`。

**三种遍历的代码区别：**

- 前序：先 `append(root.val)`，再递归左、右子树。
- 中序：先递归左子树，再 `append(root.val)`，最后递归右子树。
- 后序：先递归左、右子树，最后 `append(root.val)`。

例如下面这棵树：

```text
       1
      / \
     2   3
    / \
   4   5
```

对应结果：

- 前序：`[1, 2, 4, 5, 3]`
- 中序：`[4, 2, 5, 1, 3]`
- 后序：`[4, 5, 2, 3, 1]`

## 三、Python 相关知识

1. **自定义类与对象**：`TreeNode` 定义二叉树节点，`self.val`、`self.left`、`self.right` 分别保存节点值、左子节点和右子节点。每个节点都是一个对象，通过属性引用连接成树。
2. **递归函数**：函数内部调用自身，例如 `f(root.left)`。每次调用都会处理一棵更小的子树，直到遇到空节点，逐层返回。
3. **递归终止条件**：`if root is None: return` 是防止无限递归的关键。空节点没有值，因此不能执行 `root.val`。
4. **闭包与变量共享**：内部函数 `f()` 可以直接访问外部函数中的 `res`，并通过 `append()` 修改列表，不需要使用 `global` 或 `nonlocal`。
5. **类型注解**：`Optional[TreeNode]` 表示节点或 `None`；`TreeNode | None` 是 Python 3.10+ 的写法。`List[int]` 表示整数列表，现代 Python 也可以写成 `list[int]`。
6. **return 的作用**：递归函数中的 `return` 用于结束当前调用。这里不需要返回子树结果，因为所有节点值都直接添加到共享的 `res` 列表中。

## 四、复杂度分析

设二叉树共有 n 个节点：

- **时间复杂度：O(n)**。每个节点恰好访问一次，每次访问只进行常数次操作。
- **空间复杂度：O(h)**。递归调用栈最多保存树高 h 层的调用信息；不考虑返回结果列表的空间。若将结果列表也计算在内，总空间为 O(n)。

## 五、重点总结

前序、中序、后序遍历本质上是同一套递归框架，区别只有 `append()` 的位置。学习时应重点掌握递归终止条件、左右子树递归调用，以及根节点的访问时机。记住：**中、左、右分别代表根节点、左子树、右子树，调整根节点的访问位置就能实现三种遍历。**
