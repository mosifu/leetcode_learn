# 104. 二叉树的最大深度

## 一、解题思路：递归（后序遍历）

本题要求计算二叉树的最大深度，即从根节点到最远叶子节点的最长路径上包含的节点数量。可以使用递归，分别计算当前节点左、右子树的最大深度，再取较大值并加上当前节点自身的深度。

**递归过程：**

1. **确定递归终止条件**：如果当前节点 `root is None`，说明已经到达空节点，返回 `0`，表示空树深度为 0。
2. **递归计算左子树**：`left = self.maxDepth(root.left)`，得到左子树的最大深度。
3. **递归计算右子树**：`right = self.maxDepth(root.right)`，得到右子树的最大深度。
4. **合并结果**：`return max(left, right) + 1`，取左右子树深度的最大值，再加上当前节点自身的 1 层，得到以当前节点为根的树的最大深度。

## 二、递归过程示例

以 `[3,9,20,null,null,15,7]` 为例：

```text
        3
       / \
      9   20
         /  \
        15   7
```

递归从根节点向下展开，直到遇到 `None`，再逐层向上返回结果：

- 节点 9：左右子树深度均为 0，返回 `max(0,0)+1 = 1`。
- 节点 15、7：分别返回 1。
- 节点 20：返回 `max(1,1)+1 = 2`。
- 节点 3：返回 `max(1,2)+1 = 3`。

最终最大深度为 **3**。

## 三、知识点总结

- `root is None`：判断当前节点是否为空，作为递归的终止条件。
- `max(left, right)`：Python 内置函数，返回两个数中的较大值。
- `TreeNode | None`：Python 3.10+ 的联合类型注解，表示参数可以是 `TreeNode` 对象，也可以是 `None`。
- 本题属于**后序遍历思想**：先处理左子树，再处理右子树，最后根据左右子树的结果计算当前节点的结果。

## 四、复杂度分析

- **时间复杂度：O(n)**，每个节点只访问一次，n 为二叉树节点数量。
- **空间复杂度：O(h)**，递归调用栈的深度取决于树的高度 h。平衡树约为 O(log n)，最坏情况下（链状树）为 O(n)。

**核心思想：** 当前节点的最大深度 = 左右子树最大深度中的较大值 + 1。通过递归将大问题拆分为左右子树的子问题，再逐层合并结果。
