# LeetCode 1109：航班预订统计

## 一、解题思路：差分数组 + 前缀和

**核心思想：用差分数组记录区间的变化量，再通过前缀和还原每个航班的座位总数。**

### 1. 初始化差分数组

创建 `diff = [0] * (n + 1)`。航班编号从 1 开始，而 Python 索引从 0 开始，因此航班 `i` 对应索引 `i-1`。额外的第 `n` 个索引用于记录最后一个航班之后的变化。

### 2. 处理预订记录

对于 `[first, last, seats]`，表示区间内每个航班增加 `seats` 个座位。只需更新两个位置：

- `diff[first-1] += seats`：从起始航班开始增加座位。
- `diff[last] -= seats`：在结束航班之后撤销这部分增量。

例如 `[2, 3, 20]`，更新 `diff[1] += 20`、`diff[3] -= 20`，表示航班 2、3 各增加 20 个座位。

### 3. 还原最终答案

差分数组保存的是变化量，不是实际座位数。遍历前 `n` 个位置，累加当前差分值：

```python
current_seats += diff[i]
answer[i] = current_seats
```

每次累加得到当前航班的总座位数。额外位置 `diff[n]` 不需要写入答案。

## 二、Python 知识点

- `[0] * (n+1)`：创建长度为 `n+1` 的列表。
- `range(n)`：遍历索引 `0` 到 `n-1`，不包含 `n`。
- `+=`、`-=`：分别表示累加和累减。
- `for first, last, seats in bookings`：通过序列解包获取每条预订记录的三个值。

## 三、复杂度分析

设预订记录数为 \(m\)，时间复杂度为 \(O(n+m)\)，空间复杂度为 \(O(n)\)。

**记忆口诀：区间起点加，终点之后减；差分记变化，前缀和还原。**
