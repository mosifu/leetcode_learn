# LeetCode 56：合并区间

## 一、解题思路：排序 + 贪心

核心思想：**先按区间左端点升序排序，再依次比较相邻区间，重叠就合并，不重叠就保存当前区间。**

### 1. 排序区间
使用 `intervals.sort(key=lambda x: x[0])`，按照每个区间的起点升序排列。排序后，只需从左向右遍历，就能判断当前区间与下一个区间是否重叠。

### 2. 判断并合并
初始化 `current_interval = intervals[0]`，将其作为当前待合并区间。每次取出下一个区间 `next_interval`：

- 若 `current_interval[1] >= next_interval[0]`，说明两个区间重叠或端点相接，更新右端点为两者右端点的最大值。
- 若不重叠，则将当前区间加入 `res`，再令 `current_interval = next_interval`。

### 3. 保存最后一个区间
循环结束后，最后一个待合并区间尚未必加入结果，因此需要执行 `res.append(current_interval)`，避免遗漏。

## 二、Python 匿名函数 lambda

语法：`lambda 参数: 表达式`。例如 `lambda x: x[0]` 接收一个区间列表 `x`，返回其第一个元素，即区间起点。它相当于：

```python
def get_start(x):
    return x[0]
```

`sort(key=...)` 会根据 `key` 返回的值排序，而不是直接改变区间结构。注意：`sort()` 会原地修改原列表，返回值是 `None`。

## 三、复杂度与注意事项

设区间数量为 n，排序时间为 O(n log n)，遍历为 O(n)，总时间复杂度为 **O(n log n)**，额外结果空间为 O(n)。代码默认 `intervals` 非空，否则访问 `intervals[0]` 会报错。实际提交时可先判断空列表。由于排序会修改输入，若需保留原数组，可使用 `sorted(intervals, key=lambda x: x[0])`。
