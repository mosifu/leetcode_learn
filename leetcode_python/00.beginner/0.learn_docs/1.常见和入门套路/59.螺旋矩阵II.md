# LeetCode 59：螺旋矩阵 II

## 一、解题思路

采用**分层模拟 + 四个方向遍历**，用 `index` 表示当前层的起始位置，`count` 表示下一个要填入的数字。先创建 `n × n` 的零矩阵，然后每一层按照顺时针顺序填充：

1. **从左到右**：遍历最上面一行，行索引固定为 `index`。
2. **从上到下**：遍历最右边一列，列索引固定为 `n-1-index`。
3. **从右到左**：遍历最下面一行，行索引固定为 `n-1-index`。
4. **从下到上**：遍历最左边一列，列索引固定为 `index`。

每填入一个数字，`count += 1`；每完成一圈，`index += 1`，向内收缩一层。对于奇数 `n`，最后会剩下中心位置，需要单独填入 `count`。

## 二、Python 知识点

- **二维列表**：`[[0] * n for _ in range(n)]` 创建独立的 `n` 行列表，避免使用 `[[0] * n] * n` 导致多行引用同一对象。
- **`range()` 左闭右开**：`range(start, stop)` 包含 `start`，不包含 `stop`。因此遍历最上面一行时使用 `range(index, n-1-index)`，避免重复填充右上角。
- **倒序遍历**：`range(n-1-index, index, -1)` 每次减一，用于从右向左或从下向上填充。
- **整数除法与取模**：`n // 2` 得到中心索引；`n % 2 == 1` 判断 `n` 是否为奇数。
- **二维索引**：`matrix[i][j]` 表示第 `i` 行、第 `j` 列，索引从 `0` 开始。

## 三、边界与复杂度

需要特别注意：四个方向的遍历范围必须避免重复填充拐角；`n = 1` 时，中心位置就是唯一元素。你的代码使用 `while not count >= n*n`，但该条件会在填完前 `n²-1` 个元素后停止，导致偶数矩阵也可能漏填。更稳妥的做法是按层循环，并确保所有边界处理完成，或将条件改为 `while count <= n*n`，再配合边界判断避免越界与重复填充。

**时间复杂度：** \(O(n^2)\)，每个元素最多填充一次。

**空间复杂度：** \(O(n^2)\)，用于存储输出矩阵。

## 补充：边界收缩法

除了分层遍历，还可以使用**上下左右四个边界**模拟顺时针填充。初始化 `top = 0`、`bottom = n-1`、`left = 0`、`right = n-1`，每完成一个方向，就收缩对应边界。

1. **从左到右**：遍历 `range(left, right+1)`，填充上边界，随后 `top += 1`。
2. **从上到下**：遍历 `range(top, bottom+1)`，填充右边界，随后 `right -= 1`。
3. **从右到左**：遍历 `range(right, left-1, -1)`，填充下边界，随后 `bottom -= 1`。
4. **从下到上**：遍历 `range(bottom, top-1, -1)`，填充左边界，随后 `left += 1`。

**Python 知识点：**
- `range(start, stop)` 左闭右开，因此正向遍历要使用 `right+1`，倒序遍历要使用 `left-1`。
- `n**2` 表示 \(n^2\)，但循环条件应为 `count <= n**2`。
- 每轮填充前应检查 `top <= bottom and left <= right`，避免中心行或列被重复填充。更稳妥的方式是在每次收缩后判断边界是否交错，再决定是否继续下一个方向。

**复杂度：** 时间 \(O(n^2)\)，矩阵空间 \(O(n^2)\)。核心区别：分层法用 `index` 控制层数，边界法用四个变量逐步缩小待填区域。
