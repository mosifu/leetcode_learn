# LeetCode 41：缺失的第一个正数

## 一、解题思路：原地哈希 + 交换归位

核心思想：将正整数 `x` 放到索引 `x-1` 的位置，使数字 `1` 放在索引 `0`、数字 `2` 放在索引 `1`。最后遍历数组，第一个不满足 `nums[i] == i+1` 的位置，其 `i+1` 就是缺失的最小正整数。

### 1. 原地交换
使用 `while i < len(nums)` 遍历。当 `nums[i] == i+1` 时，当前元素已经归位，索引后移。否则，若当前值满足 `1 <= curr_num <= len(nums)`，且目标位置的值不同，就交换 `nums[i]` 和 `nums[curr_num-1]`。交换后暂时不移动 `i`，因为换过来的元素可能仍需归位。负数、零、过大的数，以及重复值则跳过，避免无效交换或死循环。

### 2. 查找缺失值
归位完成后，从左向右检查 `nums[i] == i+1`。第一个不匹配的位置说明正整数 `i+1` 缺失，直接返回它。

### 3. 为什么最后返回 `len(nums)+1`？
如果遍历后所有位置都满足 `nums[i] == i+1`，数组就包含了 `1` 到 `n`。因此最小缺失正整数只能是下一个数 `n+1`。例如 `[1,2,3]` 返回 `4`。

## 二、Python 新知识点

- **多重条件判断**：`1 <= curr_num <= len(nums)` 是链式比较，等价于 `curr_num >= 1 and curr_num <= len(nums)`。
- **解包交换**：`nums[a], nums[b] = nums[b], nums[a]` 先计算右侧两个值，再同时赋给左侧，无需临时变量，避免先赋值覆盖原数据。
- **索引与元素值**：元素 `x` 对应目标索引 `x-1`，因为列表从索引 `0` 开始。
- **`pass`**：表示什么也不做，可用于占位；这里也可以改成 `if nums[i] != i+1: return i+1`，让逻辑更简洁。

## 三、复杂度分析

时间复杂度为 **O(n)**：每次有效交换都会将一个数字放到正确位置，每个位置归位后不会再被无效交换反复处理；空间复杂度为 **O(1)**，因为只修改原数组，仅使用常数个变量。
