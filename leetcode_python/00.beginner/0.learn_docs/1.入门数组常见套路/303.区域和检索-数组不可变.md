# LeetCode 303：区域和检索——数组不可变

## 一、解题思路

**方法一：遍历求和。** 初始化时保存原数组，每次调用 `sumRange(left, right)`，使用 `range(left, right + 1)` 遍历并累加，时间复杂度为 \(O(n)\)，查询较多时效率较低。

**方法二：前缀和。** 初始化时创建 `len(nums)+1` 长度的 `self.sums`，其中 `self.sums[k]` 表示原数组前 `k` 个元素之和。递推公式为 `self.sums[i+1] = self.sums[i] + nums[i]`。查询时直接计算 `self.sums[right+1] - self.sums[left]`，时间复杂度为 \(O(1)\)。

## 二、前缀和的边界问题

关键是**前缀和比原数组多一个元素**，并令 `self.sums[0] = 0`，表示前 0 个元素之和。

例如 `nums = [-2, 0, 3]`，前缀和为 `self.sums = [0, -2, -2, 1]`。查询 `[0, 2]` 时，结果为 `self.sums[3] - self.sums[0] = 1`。

- `right + 1`：因为 `right` 是包含在查询范围内的，前缀和下标需要向后移一位。
- `left`：减去左边界之前所有元素的和，恰好保留 `nums[left]` 到 `nums[right]`。
- 当 `left = 0` 时，减去 `self.sums[0]` 即可，不需要特殊判断。

## 三、Python 知识点

- `__init__` 是构造方法，创建对象时自动执行。
- `self.sums` 是实例属性，供不同方法共享。
- `[0] * (len(nums)+1)` 创建指定长度的初始列表。
- `range(left, right+1)` 左闭右开，因此要加 `1` 才能遍历到 `right`。
- `list[int]` 是类型注解，表示整数列表。
- 不建议用 `sum` 作为变量名，因为它会遮蔽 Python 内置求和函数。

**复杂度对比：** 遍历法预处理 \(O(1)\)、单次查询 \(O(n)\)；前缀和法预处理 \(O(n)\)、单次查询 \(O(1)\)，额外空间均为 \(O(n)\)（前缀和需要保存新列表）。
