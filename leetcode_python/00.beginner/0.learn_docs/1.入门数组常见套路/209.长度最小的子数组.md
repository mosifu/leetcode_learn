# LeetCode 209：长度最小的子数组

## 一、解题思路：滑动窗口

使用快慢指针维护一个连续子数组窗口，`slow` 指向窗口左端，`fast` 指向窗口右端，`my_sum` 记录窗口内元素之和，`min_len` 记录最小长度。

1. 初始化 `slow = fast = 0`、`my_sum = 0`、`min_len = float('inf')`。
2. 快指针向右移动，将 `nums[fast]` 加入窗口，更新 `my_sum`。
3. 当 `my_sum >= target` 时，说明窗口满足条件：
   - 更新最小长度：`min_len = min(min_len, fast - slow + 1)`。
   - 减去左端元素：`my_sum -= nums[slow]`。
   - 慢指针右移：`slow += 1`，尝试缩小窗口。
4. 快指针继续右移，直到遍历完整个数组。
5. 如果 `min_len` 仍为无穷大，说明不存在符合条件的子数组，返回 `0`；否则返回 `min_len`。

## 二、核心知识点

- **可变长度滑动窗口**：快指针扩大窗口，慢指针缩小窗口。
- **内层 `while`**：满足条件后持续缩小窗口，寻找当前右端点对应的最短有效子数组。
- **窗口长度**：`fast - slow + 1`，因为左右端点都包含在窗口内。
- **移除元素的顺序**：先减去 `nums[slow]`，再执行 `slow += 1`，逻辑更清晰。
- **无穷大初始化**：`float('inf')` 用于记录最小值，便于后续比较。
- **复杂度**：时间 `O(n)`，空间 `O(1)`。两个指针都只向右移动。

## 三、适用条件

题目中的数组元素均为正整数，因此窗口扩大时总和不减小，窗口缩小时总和不增加，适合使用滑动窗口。若数组包含负数，这种方法不一定正确。

**记忆口诀：快指针扩窗口，慢指针缩窗口；满足条件就更新答案并尝试缩小。**
