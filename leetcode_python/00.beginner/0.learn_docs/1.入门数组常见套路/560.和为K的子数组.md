# LeetCode 560：和为 K 的子数组

## 一、解题思路：前缀和 + 哈希表

**核心思想：将连续子数组求和转化为两个前缀和相减，并用哈希表统计历史前缀和出现的次数。**

1. **计算前缀和**：定义 `pre_sums[i]` 为 `nums` 前 `i` 个元素的和，初始化 `pre_sums[0] = 0`，递推公式为 `pre_sums[i+1] = pre_sums[i] + nums[i]`。数组长度为 `len(nums)+1`，便于处理从索引 `0` 开始的子数组。
2. **推导查找条件**：若子数组 `nums[j:i]` 的和为 `k`，则 `pre_sums[i] - pre_sums[j] = k`，所以需要寻找历史前缀和 `pre_sums[j] = pre_sums[i] - k`。
3. **哈希表统计**：遍历前缀和，计算 `other = i_num - k`。若 `other` 存在于 `cache`，就将 `cache[other]` 加入答案，因为每次历史出现都对应一个不同的子数组。
4. **更新哈希表**：使用 `cache[i_num] = cache.get(i_num, 0) + 1` 记录当前前缀和。必须先查询、后记录，避免当前位置与自身配对，产生空子数组。

## 二、Python 知识点

- `List[int]` 表示整数列表；现代 Python 也可写 `list[int]`。
- `[0] * (len(nums)+1)` 创建指定长度的列表。
- `enumerate()` 可同时遍历索引和值；若不需要索引，直接 `for i_num in pre_sums` 更简洁。
- `dict.get(key, 0)`：键不存在时返回默认值 `0`。
- `if other in cache` 检查字典中是否存在该键，平均时间复杂度为 \(O(1)\)。

## 三、复杂度与注意事项

时间复杂度为 \(O(n)\)，空间复杂度为 \(O(n)\)。由于数组可能包含负数，前缀和不一定递增，不能直接用普通滑动窗口解决。注意：题目要求连续且非空的子数组，哈希表存储的是前缀和的**出现次数**，而不只是是否存在。
