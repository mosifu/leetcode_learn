# LeetCode 21：合并两个有序链表

## 一、解题思路

本题使用**虚拟头节点（dummy）+ 双指针**。由于两个链表已经按非递减顺序排列，每次比较 `list1` 和 `list2` 当前节点的值，将较小节点接入合并链表，再移动对应指针。

1. **初始化**：创建虚拟头节点 `dummy = ListNode()`，令 `current = dummy`。`dummy` 用于固定合并链表的起点，`current` 负责指向当前合并链表的末尾。
2. **比较连接**：当两个链表都不为空时，比较 `list1.val` 与 `list2.val`。若前者较小，就执行 `current.next = list1`；否则执行 `current.next = list2`。
3. **移动指针**：将被选中链表的指针移动到下一个节点，再执行 `current = current.next`，准备连接下一个节点。
4. **处理剩余节点**：循环结束时，至少一个链表为空。将另一个链表直接接到 `current.next`，因为其剩余部分已经有序。
5. **返回结果**：返回 `dummy.next`，跳过虚拟头节点，得到真正的合并链表。

## 二、Python 相关知识

- **对象与引用**：`current = dummy` 不会复制节点，而是让两个变量引用同一个对象。因此，执行 `current.next = list1`，实际上也改变了 `dummy.next` 指向的节点。
- **属性访问与赋值**：`list1.val` 读取节点值；`current.next = list1` 修改节点的连接关系。
- **`is not None`**：判断引用是否不是空值，避免访问空节点的属性。
- **逻辑运算符 `and`**：只有两个链表都不为空时才进入循环，保证可以安全访问 `.val`。
- **引用移动与结构修改**：`list1 = list1.next` 只是移动变量的引用；`current.next = list1` 才是建立节点连接。
- **虚拟头节点**：它的值没有实际意义，主要用于统一处理首个节点和后续节点，减少特殊判断。

## 三、复杂度分析

设两个链表长度分别为 \(m\) 和 \(n\)。每个节点最多处理一次，时间复杂度为 **\(O(m+n)\)**。算法复用原有节点，只创建一个虚拟节点，额外空间复杂度为 **\(O(1)\)**。

**核心记忆：** `current.next` 负责连接，`list1/list2` 负责遍历，`current` 负责推进合并链表的末尾。
