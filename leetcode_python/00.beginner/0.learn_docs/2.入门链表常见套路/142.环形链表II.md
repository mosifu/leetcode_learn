# LeetCode 142：环形链表 II

## 一、解题思路：Floyd 判圈算法

本题要求返回链表入环的第一个节点，无环则返回 `None`。使用**快慢指针**分两阶段解决。

**第一阶段：寻找相遇点。** 初始化 `slow = fast = head`。每轮慢指针走一步，快指针走两步。循环条件 `fast is not None and fast.next is not None` 保证快指针可以安全移动两步。如果两指针相遇，说明存在环；若快指针到达空节点，则无环，返回 `None`。

**第二阶段：寻找入环点。** 将 `slow` 移回 `head`，`fast` 留在首次相遇点。两个指针每轮都走一步，再次相遇的位置就是入环点，返回该节点。

## 二、为什么第二次相遇是入环点？

设头节点到入环点距离为 \(a\)，入环点到首次相遇点距离为 \(b\)，环长为 \(L\)。首次相遇时，快指针比慢指针多走的距离是环长的整数倍，因此慢指针路程满足 \(a+b=kL\)。整理得 \(a=(k-1)L+(L-b)\)。这说明，从头节点走 \(a\) 步，与从首次相遇点走 \(a\) 步，都会到达入环点。

## 三、Python 相关知识

- **多重赋值**：`slow = fast = head` 让两个变量引用同一个节点对象，不会复制链表。
- **短路求值**：`and` 从左向右判断，左侧为假时不再计算右侧，避免访问 `None.next`。
- **引用与属性**：`slow = slow.next` 移动引用，不改变节点连接；`.next` 表示后继节点。
- **`is` 与 `==`**：`is` 判断是否为同一个对象；`==` 判断对象是否相等。当前 `ListNode` 未重写 `__eq__()`，两者效果相同，但推荐用 `slow is fast` 判断节点相遇。
- **类型注解**：`Optional[ListNode]` 表示返回节点或 `None`。

## 四、复杂度分析

时间复杂度为 **\(O(n)\)**，空间复杂度为 **\(O(1)\)**。算法只使用两个指针，不修改链表，也不需要额外集合。

**核心记忆：** 第一次相遇确定有环，第二次相遇定位入环点。
