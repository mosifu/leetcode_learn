# LeetCode 141：环形链表

## 一、解题思路：快慢指针

本题使用**快慢指针（Floyd 判圈算法）**判断链表是否存在环。初始化 `slow = head` 和 `fast = head`，两个指针都从头节点出发。每轮循环中，慢指针移动一步，快指针移动两步。如果链表存在环，快指针最终会追上慢指针；如果不存在环，快指针会先到达 `None`，或者其下一个节点为 `None`。

循环条件 `fast is not None and fast.next is not None` 保证快指针能够安全移动两步，避免访问空节点的 `.next` 属性。每次移动后，若 `slow == fast`，说明两个指针相遇，返回 `True`；循环正常结束则返回 `False`。

**执行示例：** `3 → 2 → 0 → -4`，其中 `-4` 指回节点 `2`。两个指针进入环后，快指针每轮比慢指针多走一步，因此会逐渐缩小距离，最终相遇。

## 二、相关 Python 知识

- **变量引用**：`slow = head` 和 `fast = head` 让两个变量引用同一个头节点，并非复制链表。
- **链式属性访问**：`fast.next.next` 表示沿着两个 `next` 连接向后移动两步。
- **短路求值**：`and` 从左向右判断，左侧为假时不再计算右侧，因此能防止访问 `None.next`。
- **身份与相等**：`slow == fast` 在默认的 `ListNode` 定义下比较对象身份；若重写了 `__eq__`，行为可能不同。也可以用 `slow is fast` 明确判断是否为同一节点。
- **类型注解**：`Optional[ListNode]` 表示节点或 `None`，等价于 Python 3.10+ 的 `ListNode | None`。

## 三、复杂度分析

时间复杂度为 **\(O(n)\)**：无环时最多遍历链表一次；有环时，快慢指针会在有限步数内相遇。空间复杂度为 **\(O(1)\)**：只使用两个指针，没有创建额外的数据结构。

**核心记忆：** 快指针走两步，慢指针走一步；相遇有环，快指针到达空节点则无环。
