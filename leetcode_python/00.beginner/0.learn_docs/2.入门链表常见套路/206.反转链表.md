# LeetCode 206：反转链表

## 一、解题思路

### 方法一：头插法创建新链表
初始化 `cur = None`，遍历原链表。每次使用 `cur = ListNode(head.val, cur)` 创建新节点，并将其 `next` 指向当前新链表的头节点。随后执行 `head = head.next`，继续读取原链表。由于每个新节点都插入链表头部，最终顺序反转。遍历结束后返回 `cur`。时间复杂度 O(n)，额外空间复杂度 O(n)。

### 方法二：原地反转
使用三个引用变量调整原链表的连接关系：

1. `next_node = head.next`：保存下一个节点，避免修改连接后丢失后续链表。
2. `head.next = pre`：将当前节点的指针反向连接到前一个节点。
3. `pre = head`：将前一个节点移动到当前节点。
4. `head = next_node`：继续处理下一个节点。

初始 `pre = None`，让原头节点最终指向 `None`。循环结束后，`head` 为 `None`，而 `pre` 指向反转后的头节点，因此返回 `pre`。时间复杂度 O(n)，额外空间复杂度 O(1)。

## 二、Python 语法知识

- **`None`**：表示没有对象引用。空链表的头节点为 `None`，原地反转时也用它初始化 `pre`。
- **属性访问与修改**：`head.next` 读取或修改当前节点的连接关系；`head.val` 获取节点值。
- **引用赋值**：`pre = head` 不会复制节点，而是让 `pre` 引用同一个节点对象。
- **变量命名**：建议将 `next` 改为 `next_node`，避免覆盖 Python 内置函数 `next()`。
- **类型注解**：`ListNode | None` 表示返回值或参数可以是 `ListNode` 类型，也可以是 `None`，此写法适用于 Python 3.10 及以上版本。

## 三、两种方法对比

| 比较项 | 方法一 | 方法二 |
|---|---|---|
| 创建新节点 | 是 | 否 |
| 修改原链表 | 否 | 是 |
| 时间复杂度 | O(n) | O(n) |
| 额外空间 | O(n) | O(1) |

**核心记忆：** 方法一不断头插新节点；方法二依次反转原节点的 `next`。原地反转时，务必先保存 `head.next`，再修改连接，避免后续节点丢失。
