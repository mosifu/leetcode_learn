## LeetCode 227：基本计算器 II

### 一、解题思路

本题的关键是处理运算符优先级。使用栈保存计算结果，并通过 `pre_sign` 记录上一个运算符，遇到新运算符或遍历到字符串末尾时，才处理前一个数字。

1. **遍历并拼接数字**：逐字符遍历字符串，使用 `isdigit()` 判断是否为数字。通过 `num = num * 10 + int(c)` 将连续数字拼接成完整整数。
2. **处理运算符**：当遇到非数字字符或遍历到末尾时，根据 `pre_sign` 决定如何处理当前数字：
   - `+`：将数字直接压入栈。
   - `-`：将数字取负后压入栈。
   - `*`：弹出栈顶元素，与当前数字相乘，再将结果压入栈。
   - `/`：弹出栈顶元素，与当前数字相除，再将结果压入栈。
3. **更新状态**：将当前字符记录为新的 `pre_sign`，并将 `num` 重置为 0。
4. **计算结果**：遍历结束后，栈中只剩下需要相加的数，使用 `sum(stack)` 得到最终结果。

乘除法立即计算，加减法延迟到最后求和，因此实现了运算优先级。

### 二、Python 相关知识

1. **字符串处理**：`replace(" ", "")` 删除空格；`isdigit()` 判断字符是否为数字；`int(c)` 将数字字符转换为整数。
2. **多位数拼接**：`num * 10 + int(c)` 利用十进制规则逐位构造整数，例如 `123`：`1 → 12 → 123`。
3. **栈操作**：列表的 `append()` 和 `pop()` 分别实现入栈和弹栈，`stack[-1]` 可以查看栈顶。
4. **负数处理**：减法可以转化为加上负数，例如 `3-2` 等价于 `3+(-2)`，最后统一求和。
5. **除法截断**：Python 的 `//` 是向负无穷取整，而题目要求向零截断。可以用 `abs(a) // abs(b)` 计算绝对值，再根据结果符号恢复正负，避免浮点精度问题。
6. **末尾处理**：`i == n-1` 确保最后一个数字即使后面没有运算符，也能进入计算流程。

### 三、复杂度分析

设字符串长度为 n。遍历字符串一次，栈操作均为均摊 O(1)，最终求和为 O(n)，因此时间复杂度为 **O(n)**，栈的空间复杂度为 **O(n)**。
