# LeetCode 739：每日温度

## 一、解题思路：单调递减栈

本题使用**单调栈（Monotonic Stack）**解决下一个更大元素问题。栈中存储的是数组索引，而不是温度值，并且保证栈底到栈顶对应的温度保持单调递减。

1. **初始化**：创建栈 `stack = [0]`，存储待寻找更高温度的日期索引；创建答案数组 `answer`，全部初始化为 0，表示默认之后没有更高温度。
2. **遍历数组**：使用 `for i in range(1, n)` 从第二天开始遍历。
3. **比较温度**：当栈不为空，且当前温度 `temperatures[i]` 大于栈顶索引对应的温度时，说明当前日期就是栈顶日期遇到的下一个更高温度。
4. **计算间隔**：通过 `stack.pop()` 取出待处理索引 `index`，计算 `i - index`，得到等待天数并记录到 `answer[index]`。
5. **继续比较并入栈**：使用 `while` 持续处理栈中所有比当前温度低的日期，直到栈为空或栈顶温度不低于当前温度。最后将当前索引 `i` 入栈。

遍历结束后，栈中剩余索引对应的日期始终没有找到更高温度，答案保持为 0。

## 二、Python 相关知识

- **列表初始化**：`[0] * n` 创建长度为 n、元素均为 0 的列表，适合初始化答案数组。
- **`range()`**：`range(1, n)` 生成从 1 到 n-1 的索引序列，不包含 n。
- **列表模拟栈**：`append(i)` 将索引压入栈，`pop()` 弹出栈顶元素，`stack[-1]` 获取栈顶索引但不删除。
- **逻辑短路**：`stack and ...` 先判断栈是否非空，避免空栈访问 `stack[-1]`。
- **`while` 循环**：当前温度可能一次解决多个历史日期的问题，因此需要持续弹出，而不是只比较一次。
- **索引与值分离**：保存索引可以同时获取温度和计算日期间隔。

## 三、复杂度分析

时间复杂度为 **\(O(n)\)**：虽然存在嵌套的 `while`，但每个索引最多入栈一次、出栈一次。空间复杂度为 **\(O(n)\)**：答案数组和单调栈最多都存储 n 个元素。

**核心记忆：** 栈中保存尚未找到更高温度的日期索引，当前温度更高时，就不断弹出并计算等待天数。
