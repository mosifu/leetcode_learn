## LeetCode 155：最小栈

### 一、解题思路

使用两个栈：`stack` 保存所有正常入栈的元素；`min_stack` 只保存当前最小值发生变化时的元素。

- **push(value)**：元素先进入主栈。如果最小栈为空，或者新元素小于等于最小栈顶元素，则同时压入最小栈。使用 `<=` 是为了保留重复出现的最小值。
- **pop()**：弹出主栈顶元素。如果它等于最小栈顶元素，说明当前最小值被删除，最小栈也需要同步弹出。
- **top()**：返回主栈顶元素。
- **getMin()**：返回最小栈顶元素。

例如，依次压入 `-2、0、-3`：

| 操作 | 主栈 | 最小栈 |
|---|---|---|
| push(-2) | [-2] | [-2] |
| push(0) | [-2,0] | [-2] |
| push(-3) | [-2,0,-3] | [-2,-3] |
| pop() | [-2,0] | [-2] |

弹出 `-3` 后，最小值自动恢复为 `-2`。

### 二、Python 相关知识

1. **列表模拟栈**：Python 没有必须使用的独立栈类型，通常使用 `list` 实现。`append()` 入栈，`pop()` 弹出栈顶，`stack[-1]` 获取栈顶但不删除。
2. **空列表判断**：`if not self.min_stack` 可以判断列表是否为空。空列表的布尔值为 `False`，非空列表为 `True`。
3. **短路求值**：`or` 左侧为真时，不再执行右侧。因此 `not self.min_stack or value <= self.min_stack[-1]` 可以避免空列表访问 `[-1]`。
4. **重复最小值处理**：使用 `<=` 而不是 `<`，确保相同的最小值也进入辅助栈，避免弹出一个最小值后丢失另一个。
5. **负数与整数**：Python 的 `int` 支持任意精度整数，不需要像 Java 一样担心固定 32 位整数溢出。

### 三、复杂度分析

每个操作只涉及常数次列表操作，因此 `push、pop、top、getMin` 的时间复杂度均为 **O(1)**；两个栈最多存储 n 个元素，空间复杂度为 **O(n)**。
