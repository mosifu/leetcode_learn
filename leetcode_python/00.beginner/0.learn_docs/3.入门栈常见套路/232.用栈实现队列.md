## LeetCode 232：用栈实现队列

### 一、解题思路

使用两个栈实现队列：

- `in_stack`：负责接收入队元素。
- `out_stack`：负责存储待出队元素。

**1. push(x)：入队**

直接使用 `in_stack.append(x)`，将新元素压入入栈。

**2. pop()：出队**

先判断 `out_stack` 是否为空：
- 如果不为空，直接执行 `out_stack.pop()`，返回栈顶元素。
- 如果为空，则将 `in_stack` 中的元素依次弹出并压入 `out_stack`，完成顺序反转，再弹出栈顶元素。

**3. peek()：查看队首**

与 `pop()` 类似，先判断 `out_stack` 是否为空。若为空，先进行元素转移，最后通过 `out_stack[-1]` 获取队首元素，但不删除。

**4. empty()：判断队列是否为空**

只有两个栈都为空时，队列才为空。使用 `not self.in_stack and not self.out_stack` 即可判断。

### 二、Python 相关知识

1. **列表模拟栈**：`append()` 表示入栈，`pop()` 表示弹出栈顶，`[-1]` 获取栈顶元素但不删除。
2. **列表布尔判断**：空列表的布尔值为 `False`，非空列表为 `True`，因此 `if self.out_stack` 可以直接判断栈是否为空。
3. **逻辑运算符**：`or` 表示至少一个条件为真，`and` 表示两个条件都为真。例如 `if self.out_stack or self.in_stack` 判断是否至少有一个栈非空。
4. **while 循环**：`while self.in_stack` 在入栈不为空时持续转移元素，直到所有元素转移完成。
5. **返回值与修改操作**：`append()` 只修改列表，不返回新增元素；`pop()` 会删除并返回栈顶元素。

### 三、复杂度分析

`push()` 时间复杂度为 O(1)；单次 `pop()` 和 `peek()` 最坏为 O(n)，但每个元素最多从入栈转移到出栈一次，因此均摊时间复杂度为 O(1)。`empty()` 为 O(1)。空间复杂度为 O(n)。

### 四、核心理解

只有当 `out_stack` 为空时才转移元素，不能每次出队都重新转移。这样既保证了队列顺序，也避免了重复搬运元素。
