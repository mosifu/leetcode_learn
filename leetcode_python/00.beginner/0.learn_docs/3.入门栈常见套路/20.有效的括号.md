# LeetCode 20：有效的括号

## 一、解题思路：栈（Stack）

本题使用栈的**后进先出（LIFO）**特性，判断括号是否正确匹配。因为最近出现的左括号，必须最先被右括号闭合。

1. **初始化栈和映射字典**：创建空列表 `stack`，使用字典 `map_str` 建立左括号与对应右括号的映射关系。
2. **遍历字符串**：使用 `for char in s` 逐个读取字符。
3. **处理左括号**：如果当前字符是左括号，使用 `stack.append(char)` 将其压入栈中。
4. **处理右括号**：先判断栈是否为空，再使用 `stack.pop()` 取出最近入栈的左括号，与当前右括号比较。如果不匹配或栈为空，立即返回 `False`。
5. **检查栈是否为空**：遍历结束后，如果栈中仍有左括号没有匹配，返回 `False`；否则返回 `True`。

## 二、Python 相关知识

- **列表模拟栈**：`append()` 在列表末尾添加元素，`pop()` 默认删除并返回最后一个元素。
- **字典映射**：`dict[str, str]` 是类型注解，表示键和值都是字符串。`map_str[stack.pop()]` 根据左括号查找对应的右括号。
- **成员判断**：`char in map_str.keys()` 判断字符是否为字典中的键，也可以简写为 `char in map_str`。
- **逻辑运算符**：`and` 具有短路特性，`stack and ...` 会先判断栈是否非空，避免空栈执行 `pop()`。
- **逻辑非运算**：`not` 将判断结果取反，因此 `if not (stack and ...)` 能统一处理栈为空和括号不匹配两种情况。
- **列表布尔判断**：空列表 `[]` 为 `False`，非空列表为 `True`，所以 `if stack` 可以直接判断是否还有未匹配的左括号。

## 三、复杂度分析

设字符串长度为 \(n\)，每个字符最多入栈、出栈一次，时间复杂度为 **\(O(n)\)**；最坏情况下所有字符都是左括号，空间复杂度为 **\(O(n)\)**。

**核心记忆：** 左括号入栈，右括号匹配并出栈，最后检查栈是否为空。
