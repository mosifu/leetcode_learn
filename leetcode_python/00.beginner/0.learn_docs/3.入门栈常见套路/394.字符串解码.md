## LeetCode 394：字符串解码

### 一、解题思路

使用一个栈保存遍历过程中遇到的数字、左括号和普通字符，并使用 `num` 记录当前重复次数。

1. **数字处理**：遍历字符串，遇到数字字符，通过 `num = num * 10 + int(char)` 拼接多位数。
2. **左括号处理**：遇到 `[`，将重复次数 `num` 压入栈，再将 `[` 压入栈，随后将 `num` 清零。
3. **右括号处理**：遇到 `]`，创建辅助列表 `str_stack`，不断弹出栈顶字符并保存，直到遇到 `[`。删除左括号后，再弹出重复次数。
4. **字符串解码**：由于弹出的字符顺序与原字符串相反，需要反转辅助列表，再使用 `join()` 拼接成字符串，重复 `cur_str` 次，最后将结果重新压入栈。
5. **最终结果**：遍历结束后，使用 `''.join(stack)` 拼接栈中剩余元素。

利用栈的后进先出特性，内层括号会优先解码，因此可以处理嵌套结构。

### 二、Python 相关知识

1. **`isdigit()`**：判断字符串是否由数字字符组成，适合判断遍历得到的单个字符。
2. **多位数拼接**：`num * 10 + int(char)`，例如连续读取 `1、2、3`，依次得到 `1、12、123`。
3. **`isinstance()`**：`isinstance(cur_str, int)` 判断栈顶元素是否为整数类型，用于识别重复次数。
4. **列表切片反转**：`str_stack[-1::-1]` 从最后一个元素开始，步长为 `-1`，得到反转后的新列表。
5. **`join()`**：`"".join(list)` 将字符串列表拼接成一个字符串。
6. **字符串重复**：`"abc" * 3` 得到 `"abcabcabc"`，可以直接实现解码规则。

### 三、复杂度分析

设输入长度为 n，最终解码长度为 L。遍历和栈操作需要 O(n)，字符串构造与重复拼接还需要 O(L) 级别的处理，因此时间复杂度为 **O(n+L)**，空间复杂度为 **O(n+L)**，用于存储栈和解码结果。
