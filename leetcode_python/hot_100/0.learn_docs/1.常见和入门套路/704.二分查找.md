# LeetCode 704：二分查找

## 一、解题思路：左闭右开区间

数组已经升序排列，且题目要求时间复杂度为 `O(log n)`，因此使用二分查找。每次比较中间元素与目标值，排除一半不可能的搜索范围。

1. 初始化 `left = 0`、`right = len(nums)`，表示搜索区间为 `[left, right)`，包含左端点，不包含右端点。
2. 当 `left < right` 时，计算中间下标 `mid = (left + right) // 2`。
3. 若 `nums[mid] == target`，返回 `mid`。
4. 若 `nums[mid] < target`，目标值在右侧，执行 `left = mid + 1`。
5. 若 `nums[mid] > target`，目标值在左侧，执行 `right = mid`。
6. 循环结束仍未找到目标值，返回 `-1`。

## 二、Python 语法知识

- **`len(nums)`**：获取列表长度。长度为 `n` 时，有效下标是 `0` 到 `n-1`，因此可以将 `right` 初始化为 `n`，作为右开边界。
- **`//` 整除运算**：`(left + right) // 2` 得到整数中间下标。
- **多变量赋值**：`left, right = 0, len(nums)` 可以同时初始化两个变量。
- **`while` 循环**：`left < right` 表示区间非空；当 `left == right` 时，搜索区间为空，循环结束。

## 三、关键知识点与复杂度

- **左闭右开区间**：`[left, right)`，左端点包含，右端点不包含。
- **为什么左边界是 `mid + 1`？** 中间元素已比较且不等于目标值，可以排除。
- **为什么右边界是 `mid`？** 右边界不包含在区间内，令 `right = mid` 即可排除中间位置。
- **时间复杂度：** `O(log n)`，每轮将搜索范围缩小约一半。
- **空间复杂度：** `O(1)`，只使用固定数量的变量。

注意：你的代码中 `mid` 初始化在循环外，但每轮循环末尾都会更新，因此逻辑正确；更常见的写法是在 `while` 循环内部计算 `mid`，避免重复初始化。

**记忆口诀：左闭右开，左边排除用 `mid + 1`，右边排除用 `mid`。**
