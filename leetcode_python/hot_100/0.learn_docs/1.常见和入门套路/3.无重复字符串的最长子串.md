# LeetCode 3：无重复字符的最长子串

## 一、解题思路：滑动窗口 + 集合

使用左右指针维护一个不含重复字符的窗口，`max_set` 用于记录当前窗口中的字符，`max_len` 记录最长子串的长度。

1. 初始化 `left = right = 0`，集合 `max_set = set()`，最大长度 `max_len = 0`。
2. 当 `right < len(s)` 时，检查 `s[right]` 是否已经存在于集合中。
3. **如果字符重复**：移除 `s[left]`，然后执行 `left += 1`，缩小窗口。此时 `right` 不动，继续检查当前字符，直到它不再重复。
4. **如果字符不重复**：将 `s[right]` 加入集合，更新 `max_len = max(max_len, len(max_set))`，然后执行 `right += 1`。
5. 遍历结束后返回 `max_len`。

## 二、核心知识点

- **滑动窗口**：维护连续的子串，而不是可以跳过字符的子序列。
- **左右指针**：`right` 负责扩展窗口，`left` 负责缩小窗口。
- **集合 `set`**：元素不重复，适合快速判断字符是否存在；`in`、`add()`、`remove()` 平均时间复杂度为 `O(1)`。
- **重复字符处理**：发现重复时，只移动左指针并移除左侧字符，直到当前字符可以加入窗口。
- **窗口长度**：`len(max_set)` 等于当前窗口长度，因为窗口内字符始终不重复；也可以使用 `right - left + 1`。
- **边界情况**：空字符串不会进入循环，最终返回 `0`。

## 三、复杂度分析

- 时间复杂度：`O(n)`。每个字符最多被左右指针各处理一次。
- 空间复杂度：`O(min(n, 字符集大小))`，集合最多保存当前窗口内的不同字符。

**记忆口诀：右指针扩窗口，遇到重复就移动左指针；无重复时更新最大长度。**
