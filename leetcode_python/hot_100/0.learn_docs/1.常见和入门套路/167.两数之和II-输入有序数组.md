# 两数之和 II：有序数组

## 一、题目约束
- 数组 `numbers` 按非递减顺序排列，允许重复元素。
- 只存在一个有效答案，不能重复使用同一个元素。
- 返回下标从 **1 开始**，而 Python 下标从 0 开始，因此返回时需要 `+1`。
- 只能使用常数级额外空间。

## 二、解法一：哈希表
遍历数组，对当前数字 `num`，计算补数 `other = target - num`。先检查补数是否存在于字典 `cache` 中；若存在，返回 `[cache[other]+1, index+1]`，否则保存 `cache[num] = index`。

- 时间复杂度：平均 `O(n)`。
- 空间复杂度：`O(n)`。
- 缺点：需要额外字典，不满足常数级空间要求。

## 三、解法二：双指针
初始化 `left = 0`、`right = len(numbers)-1`，分别指向数组两端。在 `while left < right` 中计算两数之和：
1. 等于 `target`：返回 `[left+1, right+1]`。
2. 小于 `target`：左指针右移 `left += 1`，尝试增大和。
3. 大于 `target`：右指针左移 `right -= 1`，尝试减小和。

数组有序是双指针成立的关键，每次移动都能排除一部分不可能的组合。

## 四、复杂度与知识点
- 时间复杂度：`O(n)`，每个指针最多移动数组长度数量级的步数。
- 空间复杂度：`O(1)`，只使用固定数量的变量。
- `enumerate(numbers)` 可同时获取下标和值。
- `while left < right` 确保两个指针不会指向同一个元素。
- 解题经验：根据题目约束选择算法；普通两数之和可用哈希表，有序数组且要求常数级额外空间时，优先考虑双指针。
