# LeetCode 26：删除有序数组中的重复项

## 一、解题思路：快慢指针

数组已经按非递减顺序排列，相同元素会相邻出现，因此可以使用快慢指针原地去重，无须创建新数组。

- `read`：快指针，负责读取数组元素。
- `write`：慢指针，指向当前已去重区域的最后一个位置。

具体步骤：

1. 初始化 `read = write = 0`。
2. 当 `read < len(nums)` 时，比较 `nums[read]` 和 `nums[write]`。
3. 如果相等，说明当前元素重复，执行 `read += 1`，跳过它。
4. 如果不相等，说明发现新的唯一元素，先执行 `write += 1`，再将 `nums[read]` 赋值给 `nums[write]`。
5. 遍历结束后，返回 `write + 1`，即唯一元素的数量。

## 二、Python 语法知识

- **`len(nums)`**：返回列表长度，用于判断快指针是否越界。
- **列表索引**：`nums[read]` 通过下标访问元素，Python 下标从 `0` 开始。
- **赋值操作**：`nums[write] = nums[read]` 修改原列表指定位置的元素，不会创建新列表。
- **`while` 循环**：只要条件成立就重复执行，适合控制指针移动。
- **`+= 1`**：等价于 `变量 = 变量 + 1`，常用于指针向右移动。
- **原地修改**：直接修改传入的 `nums`，满足题目要求的原地去重。

## 三、关键知识点与复杂度

- **为什么可以跳过重复元素？** 因为数组有序，重复元素必然相邻。
- **为什么返回 `write + 1`？** `write` 是唯一元素区域最后一个位置的下标，而元素数量比最后下标大 `1`。
- **时间复杂度：** `O(n)`，快指针最多遍历数组一次。
- **额外空间复杂度：** `O(1)`，只使用固定数量的变量。

**记忆口诀：快指针负责读，慢指针负责写；发现新元素，慢指针先移动，再覆盖写入。**
